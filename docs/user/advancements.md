# JSON 定义

进度数据位于 `data/elements-plus/advancement/`，文件名与表中括号内的 ID 一致，根进度为 `elements_plus.json`。

- 物品获取使用 `minecraft:inventory_changed`。
- 配方制作使用 `minecraft:recipe_crafted`。
- 状态效果使用 `minecraft:effects_changed`。
- 光刻机、实验桌、实验完成、芯片制造、压力伤害、自定义元件等无法由原版条件直接表达的进度，使用 `minecraft:impossible` 作为占位条件，并在对应的服务端逻辑中精确授予。
- 计算机架构、磁盘、IO 接口和机器人等内容尚未实现，相关进度暂时保留 `minecraft:impossible`，待对应内容完成后替换为实际触发条件。
