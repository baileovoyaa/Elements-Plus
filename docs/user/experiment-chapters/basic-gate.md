> 前置章节：第一个逻辑门

既然已经造出了第一个逻辑门，现在我们要来制作更多的逻辑门了。

这一章节的逻辑门将不再只有一个输入，而是通常有 A 和 B 两个输入。

- <font color=gold>或门</font>：任意一个输入为非 0，就输出 15，否则输出 0。
- <font color=gold>与门</font>：两个输入同时非 0，才输出 15，否则输出 0。
- <font color=gold>或非门</font>：任意一个输入为非 0，就输出 0，否则输出 15。
- <font color=gold>与非门</font>：两个输入同时非 0，才输出 0，否则输出 15。

```epp-experiments
或门
或非门
与非门
与门
```

---

给你一个提示：与非门和或非门并不总是与门/或门加一个非门那么简单，例如，与非门需要的晶体管数量其实比与门更少。

后面的章节，我们将经常用到这些基本逻辑门。

另外这一章同样有一个选做挑战：

- <font color=gold>短路与</font>：如果 A 非 0，输出 B，否则输出 A。
- <font color=gold>短路或</font>：如果 A 为 0，输出 B，否则输出 A。

```epp-experiments
[OPTIONAL] 短路与门
[OPTIONAL] 短路或门
```
