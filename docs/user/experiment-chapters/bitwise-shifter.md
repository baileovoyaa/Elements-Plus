> 前置章节：多位减法

上一章节我们认识了<font color=blue>补码</font>的概念。后续“<font color=blue>有符号数</font>”如果没有特殊说明，均是指补码。

位移器是一种可以将二进制数向左或向右偏移几位的元件，等效于乘2的n次幂。例如0000 1001左移3位的结果是0100 1000。

移位操作有<font color=blue>逻辑移位</font>和<font color=blue>算术移位</font>两种。其中算术移位会保留符号位，可以用于有符号数的乘除2运算。

- <font color=gold>8位位移器</font>：输入A（8位）和B（8位），输出Y为A左移B位的结果（0对应0，1对应15）。B视作<font color=blue>有符号数</font>，为负则右移。超出的位直接舍弃，缺失的位补0。
- <font color=gold>8位算术位移器</font>：输入输出同上，超出的位直接舍弃，区别是左移时缺失的位补0，右移时缺失的位补符号位。

```epp-experiments
8位位移器
8位算术位移器
```

还有一种循环位移器，它不会舍弃超出的位，而是循环移到另一侧，例如1001 0110循环左移6位后是1010 0101。这是一个可选的实验。

- <font color=gold>8位循环位移器</font>：输入A（8位）和B（8位），输出Y为A**循环**左移B位的结果（0对应0，1对应15）。B视作<font color=blue>有符号数</font>，为负则右移。超出的位直接舍弃，缺失的位补0。

```epp-experiments
[OPTIONAL] 8位循环位移器
```

还有一种模拟位移器，它会保留非0位的信号强度，而不是全变为15。例如1 2 3 4 5 6 7 8左移4位变为5 6 7 8 0 0 0 0，循环左移4位变为5 6 7 8 1 2 3 4。这也是可选实验。
 
```epp-experiments
[OPTIONAL] 8位模拟位移器
[OPTIONAL] 8位模拟循环位移器
```
