> 前置章节：介绍

信号虽然有0~15一共16种强度，但我们大部分时候关注的只是“有”和“没有”。

为此，这一章我们引入一个简单的元件——<font color=gold>放大器</font>。只要输入信号强度大于0，输出信号强度就是15。从而可以将注意力放到更上层的逻辑上，而无需在意底层的细节。

为了实现这一元件，我们需要一个可以将信号强度放大的元件。而这就是<font color=gold>晶体管</font>。

晶体管是一种可以放大信号的元件。当侧面没有输入时，它可以将正面输入放大两倍。（侧面输入以后会提到，本实验暂时用不到）

现在，尝试利用这种特性，把实验完成吧。

---

输入A，只要A的值非0即输出Y=15，否则输出Y=0。

请在光刻机中搭建电路，完成后将电路图放入上方槽位，点击“开始实验”按钮，实验将会自动进行

```epp-experiments
放大器
```
