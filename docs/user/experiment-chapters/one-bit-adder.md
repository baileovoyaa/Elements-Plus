> 前置章节：高级逻辑门

你有没有想过，在电路中我们如何表示数字？

确实，0~15 的信号强度可以表示 16 个数字。但是信号强度也有它的弊端：它难以读取和处理，且在宏观电路中会衰减。

为此，我们将引入一个更稳定、易用的数字表示方式——<font color=blue>二进制</font>。

我们日常使用的数字，逢十进一，叫做<font color=blue>十进制</font>。而二进制则是逢二进一，也就是二进制每一位只能是 0 或 1 其中一个，`1+1=(10)₂`。这样一来，就可以通过多根导线表示一个二进制数，我们不关心每一位的信号强度，只关心它“有”或者“没有”信号，分别对应 1 和 0。

---

本次实验我们将处理一位二进制数的加法。首先要做的是两个一位二进制数的加法。这个元件叫做“<font color=gold>半加器</font>”。

- <font color=gold>半加器</font>：输入 A 和 B，将 A 和 B 作为二进制数（非 0 对应 1，0 对应 0）进行相加，输出加和 S 与进位 C（1 对应 15，0 对应 0）。

为了更直观，下面将半加器所有情况列出来：

- A=0, B=0 → C=0, S=0
- A=0, B≠0 → C=0, S=15
- A≠0, B=0 → C=0, S=15
- A≠0, B≠0 → C=15, S=0

---

只处理两个一位二进制数的加法还不够，因为如果要想进行多位二进制数的加法，还需要处理进位的问题。为此我们至少需要处理三位二进制数的加法，这就是“<font color=gold>全加器</font>”。

- <font color=gold>全加器</font>：输入 A、B 和 CI，将 A、B 和 CI 作为二进制数（非 0 对应 1，0 对应 0）进行相加，输出加和 S 与进位 CO（1 对应 15，0 对应 0）。

同样，下面将全加器所有情况列出来：

- A=0, B=0, CI=0 → CO=0, S=0
- A=0, B≠0, CI=0 → CO=0, S=15
- A≠0, B=0, CI=0 → CO=0, S=15
- A≠0, B≠0, CI=0 → CO=15, S=0
- A=0, B=0, CI≠0 → CO=0, S=15
- A=0, B≠0, CI≠0 → CO=15, S=0
- A≠0, B=0, CI≠0 → CO=15, S=0
- A≠0, B≠0, CI≠0 → CO=15, S=15
