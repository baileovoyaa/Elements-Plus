> 前置章节：位移器

**注：以下两个实验均为无符号数。**

<font color=gold>乘法器</font>可以将两个数相乘，并输出相乘后的结果。由于8位相乘的结果可能超过8位，因此分别输出高8位和低8位。

通常有多种可行的方法来实现乘法器。乘法器的逻辑可能有点复杂，你可以跳过它，但你将无法制作多功能运算器的高级版。与之相比，基础版只缺少乘法功能，这不会影响计算机架构的后续构建。

- <font color=gold>乘法器（简单版）</font>：输入A（8位）和B（8位），输出Y0，只取A*B结果的低8位。
- <font color=gold>乘法器</font>：输入A（8位）和B（8位），输出Y0（8位）和Y1（8位），Y0和Y1打包A*B的16位结果，Y0是低8位，Y1是高8位。

```epp-experiments
乘法器（简单版）
乘法器
```

根据乘法的同余性质，可知在不溢出的情况下Y0正是A和B的有符号积。

---

实现组合逻辑除法器理论上可行，但实际上不建议，面积和元件数都巨大，即使画出了电路图，其造价也是高昂的。更建议使用<font color=blue>时序逻辑电路</font>，通过多个时钟周期实现。

如果你想尝试，可以做一下下面的实验，但是需要注意，这个实验是**纯组合逻辑**的，也就是你需要在同一个时钟周期内给出结果，不能使用时序元件。

- <font color=gold>除法器</font>：输入A（8位）和B（8位），输出A/B的结果的整数部分Q（8位）和余数R（8位）。约定：除数为0时，Q和R均输出0。

```epp-experiments
[OPTIONAL] 除法器
```
