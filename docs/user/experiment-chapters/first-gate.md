> 前置章节：放大器

好的，现在你应该已经通过你的第一个实验，并拥有一张编译过的电路图了。

编译过的电路图可以直接作为元件在光刻机设计页使用，你也可以将它添加到元件列表。

你应该早已注意到了光刻机的制造页，而现在是时候明白如何利用它了。

光刻机的制造页可以复制电路图、制作芯片和电路板。

如果你要复制电路图，请将电路图放在第一格作为模板，第二格放未编译的要覆盖的电路图，此时输出槽位会出现一个模板电路图的副本，取走后模板不会消耗，第二格的电路图消耗。（注：此操作将永久覆盖第二格的电路图，建议使用空电路图）

如果你要制作芯片，请将已编译的电路图放在第一格作为模板，第二格放**大于等于电路图规模**的晶片，此时将显示制作芯片所需的原料。

其中，

- 基本元件通常需要对应的紫水晶元件物品
- 高级元件需要对应的任意规模的芯片（通过此方式制造的）
- 导线需要对应格数的[金引线]和[铜引线]物品（总线乘对应倍率）
- 输入输出和总线连接/分流器不需要原料

物品栏内满足所有原料后，输出槽位会出现一个成品芯片，取走后会扣除晶片和原料。

---

学会如何制作芯片后，我们将来制作第一个逻辑门。

前面已经介绍过了晶体管的放大功能，而现在我们引入晶体管的侧向输入。侧向输入会让输出线性衰减，0对应100%的输出，15对应0%的输出（也就是完全关闭输出）。

如果你习惯使用公式，那就换句话说：晶体管最终输出的倍率是 `2*(1-侧面输入/15)`。也就是输出 `2*正面输入*(1-侧面输入/15)`。

本次我们要设计的元件是“<font color=gold>非门</font>”。它非常简单——只有一个输入A和一个输出Y。你只需要确保它在输入为0时输出15，输入不为0时输出0即可。

提示：输入为0时元件不可能凭空产生信号。想想哪个基本元件可以凭空持续产生信号？

```epp-experiments
非门
```

事实上，你只要有了这个元件，就可以造出任意复杂的<font color=blue>组合逻辑电路</font>了。

所谓<font color=blue>组合逻辑电路</font>，就是指一种输出仅依赖于当前输入状态、与电路过去状态无关的数字电路。如果你能理解，那么恭喜你，你还是有一些基础的。如果你觉得难以理解，也没关系，以后你会慢慢了解的。

如果你认为太简单了，这里给你留一个挑战：设计一个元件，输出 `15-输入`。我们把它称为“<font color=gold>模拟非门</font>”。

这个实验是可选的，你可以继续进行后续章节，后面再回来做。

```epp-experiments
[OPTIONAL] 模拟非门
```
