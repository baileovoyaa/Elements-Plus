> 前置章节：高级逻辑门

还不了解<font color=blue>二进制</font>的概念？可以先完成“<font color=gold>一位加法器</font>”章节后再来。

有一种元件，对每个二进制输入都会点亮一条单独的输出线，这就是<font color=gold>译码器</font>。而它的反向操作：将点亮的输入线输出为对应的二进制，这就是<font color=gold>编码器</font>。

---

所有的译码器逻辑都可以统称为：

输入 A0~An，输出 Y0~Ym（`m=2^(n+1)-1`）。只有一个输出为 15，其余的均为 0。根据输入的 0 和非 0 两种状态分别对应 0 和 1，组成二进制数 `x=(An...A2A1A0)₂`，具体哪个输出 15 取决于 x，只有 Yx 输出 15。

为了节省元件空间，我们将输出打包成<font color=blue>8位</font>。其中上面 Y0~Y7 分别对应下面 Y 或 Y0 的第 1~8 位，Y8~Y15 对应 Y1 的第 1~8 位。

- <font color=gold>2-4译码器</font>：输入 A0~A1，输出 Y（打包 Y0~Y3）。
- <font color=gold>3-8译码器</font>：输入 A0~A2，输出 Y（打包 Y0~Y7）。
- <font color=gold>4-16译码器</font>（可选）：输入 A0~A3，输出 Y0（打包 Y0~Y7）、Y1（打包 Y8~Y15）。

```epp-experiments
2-4译码器
3-8译码器
[OPTIONAL] 4-16译码器
```

---

然后是编码器。编码器的逻辑和译码器相反，可以统称为：

输入 A0~Am（`m=2^(n+1)-1`），输出 Y0~Yn。某个输入端为非 0 时，输出其二进制表示 `(Yn...Y2Y1Y0)₂`，其中 0 对应信号强度 0，1 对应信号强度 15。

为避免未定义行为，这里规定如果有多个输入端同时非 0，则输出所有非 0 输入对应输出的按位或的值。例如 8-3 编码器，A5（对应输出 101）和 A6（对应输出 110）同时激活时，输出 111。实际应用时通常应该避免多个输入端同时非 0。

- <font color=gold>4-2编码器</font>：输入 A（打包 A0~A3），输出 Y0~Y1。
- <font color=gold>8-3编码器</font>：输入 A（打包 A0~A7），输出 Y0~Y2。
- <font color=gold>16-4编码器</font>（可选）：输入 A0（打包 A0~A7）、A1（打包 A8~A15），输出 Y0~Y3。

```epp-experiments
4-2编码器
8-3编码器
[OPTIONAL] 16-4编码器
```

---

还有一个叫做“<font color=gold>优先编码器</font>”。和普通编码器的不同是，当多个输入端非 0 时，只有最大的输入端会实际发挥作用。这里作为可选实验。

```epp-experiments
[OPTIONAL] 4-2优先编码器
[OPTIONAL] 8-3优先编码器
[OPTIONAL] 16-4优先编码器
```
