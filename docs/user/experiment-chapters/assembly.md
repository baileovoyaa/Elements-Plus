很好，现在你已经搭建了一个计算机架构——它具备存储、计算和控制功能，理论上可以执行任何计算任务。接下来，我们将学习如何使用汇编语言来编写程序，从而利用这个计算机架构。

在前面的架构章节里，一直都是通过搭建架构来运行指定的汇编程序，而接下来的章节，你将自己编写汇编程序，通过给定的计算机架构运行，来完成特定的数据处理任务。

首先，要将前面架构制作的具备输入输出、存储、立即数、计算和跳转功能的架构编译为<font color=gold>8位基础单片机</font>。后面的汇编代码将由它来执行。这个实验将覆盖所有的指令，同时为了确保行为统一，这个实验不仅要求每个指令必须在 1 tick 内执行完，而且对未定义行为有严格要求：所有保留的指令都要视为 NOP，不执行任何操作。测试时也会随机插入一些保留指令字节，以检验你的电路是否能正确处理。

```epp-experiments
8位基础单片机
```

这个架构已经足以执行一些简单的程序，也足以通过接下来的实验。当然，对于你自己的系统，你完全可以根据需要，创造一套自己的架构，定义一套自己的指令集，编译自己的自定义元件。例如，你可以扩展功能、用更多位地址、变长指令，甚至专用电路等，打破 256 的限制，来发挥计算机架构的无限潜力。

这里也提供几个目标：<font color=gold>8位高级单片机</font>和<font color=gold>16位单片机</font>。它们在后面的章节，提供了一些指令来简化当前需要多条指令来实现的复杂操作，甚至增加了指令空间来容纳下更多条指令。在你用于控制接口和机器人，应对各种情况，设计复杂算法时，这些可能会非常有用。可以根据实际需要选择性去做。

## 伪指令

为了方便，定义一系列<font color=blue>伪指令</font>。伪指令会展开成多条指令，不属于指令集的单条编码。

| 伪指令 | 展开 | 说明 |
| --- | --- | --- |
| `LDI Rd, #imm8` | `LDL Rd, #lo`；`LDH Rd, #hi` | `Rd` 只能是 `R0`/`R1`；`lo` 为 `imm8` 的低 4 位，`hi` 为高 4 位 |
| `SETTARGET #imm8` | `LDI R0, #imm8`；`SETTARGET R0` | 会覆盖 `R0` |
| `JMP #label` | `SETTARGET #label`；`JMP` | 会覆盖 `R0` |

- 不含条件跳转 `Jcc #label`，因为设置目标会覆盖 `R0`，而条件通常也依赖 `R0`。需要带标签的条件跳转时，先用 `SETTARGET` 设好目标，再计算/装入 `R0`，最后执行 `Jcc`。
- 如果不想覆盖 `R0`，也可以手动把目标装进 `R1`，再用 `SETTARGET R1`；但要自行保存 `R1` 原来的地址。

## 编程实验

接下来的实验，我们不再需要电路图了。

把写有程序**字节码**的设备（磁盘/打孔文件均可）放入上方槽位，然后点击运行。其中程序将被执行。测试只看结果，不看过程。为了尽可能的发挥性能，大部分实验，除非明确说明，都会立即准备好输入数据和接收输出，你的程序不需要等待。

注意：实验运行过程中，修改磁盘中的程序内容将会中止实验。

实验通常会提供输入输出示例和数据范围。也有要求的最大 tick 数。你需要在给定的 tick 内完成输出。只要完成了所有预期输出，就会被视为正确；如果有一个字节输出错了，该测例就会被视为错误。

有些实验不需要通过所有测例。它们运行所有测例并计算分数。失败的测例不会阻止后续的测例。如果分数达到所需的阈值，则实验成功。无论是否成功，如果有失败测例，可以单击状态按钮检查第一次失败。

接下来实现一个简单的功能，带你快速了解相关操作。

## 回显

读取输入，并将其原封不动的输出出来。

**输入示例（16进制）**

```
48 65 6C 6C 6F 20 77 6F 72 6C 64 21
```

**输出示例（16进制）**

```
48 65 6C 6C 6F 20 77 6F 72 6C 64 21
```

**数据范围**：对于 100% 的测例，输入不超过 100 个。

**时间限制**：对于每个测例，程序需要在 512 tick 内完成输出。

**通过要求**：通过全部测例

---

打开实验桌编程页，在**实验桌内存**或**客户端文件**新建一个文件，输入以下内容。分号后面的是<font color=blue>注释</font>，作用是解释前面的指令，可以不用输入。

```
start:
    MOV R3, R3              ; DI -> DO
    JMP #start              ; 回到开头
```

其中 `JMP #start` 是伪指令，整个程序最终会展开成：

```
MOV R3, R3
LDL R0, #0x0
LDH R0, #0x0
SETTARGET R0
JMP
```

在上方槽位放一个磁盘或纸，点击汇编按钮，从而将汇编得到的字节码写入到磁盘或打孔文件，然后选择下方实验，点击运行按钮。

```epp-experiments
汇编-回显
```

## 单字节 A+B

读取两个字节，输出它们的和（溢出回绕），然后回到开头读取下一组。

**输入示例（16进制）**

```
01 02 0A 0B FF 01 AA BB
```

**输出示例（16进制）**
```
03 15 00 65
```

**数据范围**

- 对于 60% 的数据，输入不超过 10 组（20 字节）。
- 对于 80% 的数据，输入不超过 40 组。
- 对于 100% 的数据，输入不超过 80 组。

**时间限制**：对于每个测例，程序需要在 512 tick 内完成输出。

**通过要求**：通过至少 60% 的测例

```epp-experiments
汇编-单字节 A+B
```
