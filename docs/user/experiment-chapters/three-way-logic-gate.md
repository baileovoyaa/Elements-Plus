> 前置章节：高级逻辑门

之前我们做出来了一些逻辑门，而有时我们需要处理的数据是三个或以上。串联两个元件可以实现，但我们也可以集成到一个高效的元件里。

本次我们要做的是“3 路”逻辑门，输入 A、B、C，输出 Y：

- <font color=gold>三路或门</font>：任意一个输入为非 0，就输出 15，否则输出 0。
- <font color=gold>三路与门</font>：三个输入同时非 0，才输出 15，否则输出 0。
- <font color=gold>三路异或门</font>：奇数个输入非 0，输出 15；偶数个输入非 0，输出 0。
- <font color=gold>三路同或门</font>：奇数个输入非 0，输出 0；偶数个输入非 0，输出 15。

```epp-experiments
三路或门
三路与门
三路异或门
三路同或门
```
