> 前置章节：[寄存器](register.md)

接下来我们要做一种时序元件——计数器。

说到计数器，你可能会想到<font color=gold>T'触发器</font>串联。没错，这也是一种简单的计数器——纹波计数器。

- <font color=gold>8位纹波计数器</font>：输入C（1位），输出Y（8位，二进制0/15）。

当时钟步进时，如果C从0变为非0（上一刻为0，这一刻非0），输出开始增加1，从低位到高位逐tick更新（因此需要最多8tick来稳定）。

为了实现容易，初始状态是全15（对应T'触发器的初始状态反转），也就是计数是从255开始的，触发一次后才会变为0。

```epp-experiments
8位纹波计数器
```

这是红石电路中常用的一种简易计数器，但弊端也很明显——它只能实现循环递增，无法置零或置数，也不能自定义步长，因此应用范围较窄。对于后面需要搭建的架构来说，还远远不够。另外，纹波计数器作为一种异步结构，需要多个tick来完成一次计数，其固有的延迟特性在严格时序下可能带来风险。

因此，更稳妥的方案，是采用基于寄存器和加法器的同步计数器设计：

- <font color=gold>8位加法计数器</font>：输入A（8位）和E（1位），输出Y（8位，二进制0/15）。

当时钟步进时：

- E非0时是置数模式，Y设为A的二进制值；
- E为0时是自增模式，Y加上A的二进制值（溢出则循环）。

```epp-experiments
8位加法计数器
```

另外，你可能会发现，使用特定配置的谐振器和电容器，可以让模拟信号在0\~15循环，但这通常不叫计数器，而是<font color=gold>锯齿波发生器</font>。它是一种利用电容的线性充电与快速放电来产生周期性锯齿形信号强度的电路。

- <font color=gold>锯齿波发生器</font>：没有输入，输出Y，Y的信号强度在0\~15之间单向循环（15后回到0），初始输出为0。

```epp-experiments
[OPTIONAL] 锯齿波发生器
```

为了通过测试，你需要让初相为0。测试通过后获得的元件可配置。如果想了解更多，可前往<font color=gold>波形发生器</font>章节。
