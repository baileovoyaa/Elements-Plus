> 前置章节：[多功能运算器（基础版）](alu-basic.md)

现在你可以创建你的自定义元件了。

自定义元件可以让你实现自己的逻辑，不受内置元件的限制，并且可以自定义名称、图标、颜色和引脚排布。

元件并不能无限嵌套。自定义元件只能嵌套进更大规模的电路中，例如小规模只能嵌套在中规模或更大规模。

将你的电路图放入上方槽位，填写好下方的信息，然后点击运行按钮，电路图就会被编译。为了区分，自定义元件的名称会显示为斜体。自定义元件可能同名，因此需要根据其uuid唯一确定。

```epp-experiments
自定义元件
```

> 自定义元件配置表单（元件名称 描述（可选） 图标（物品/字符） 颜色 宽度 高度 预览（可调整引脚） 未使用的引脚）

注：任何规模（包括无限）都可以嵌套进无限规模的电路图中，因此嵌套层数可以不受限制。你可以在创造模式存档验证非常复杂的电路，但是注意嵌套层数过深可能会导致游戏卡顿。
