> 前置章节：多位加法器

比较器可以对两个二进制数进行比较。首先是<font color=gold>1位比较器</font>。

注意：1位比较器只认0/非0，因此任意非0值，如1和15，被认为是相等的，非0值大于0。

- <font color=gold>1位比较器</font>：输入A、B、I0和I1，输出Y0和Y1。当A<B时，输出Y0=15，Y1=0；当A>B时，输出Y0=0，Y1=15；当A=B时，输出Y0和Y1分别为I0和I1的放大值（非0即15）。

```epp-experiments
1位比较器
```

将上面的一位比较器级联，可以得到<font color=gold>8位比较器</font>。

- <font color=gold>8位比较器</font>：输入A（8位）、B（8位）、I0（1位）和I1（1位），输出Y0（1位）和Y1（1位）。当A和B代表的二进制数A<B时，输出Y0=15，Y1=0；A>B时，输出Y0=0，Y1=15；A=B时，输出Y0和Y1分别为I0和I1的放大值（非0即15）。

```epp-experiments
8位比较器
```

另外还有一种“比较器”比较的是模拟信号强度。与数字1位比较器不同，他会将1~15的信号强度视为不同的数值，例如9被认为大于8。它的实现比较复杂，这里作为可选实验。

- <font color=gold>模拟比较器</font>：输入A、B、I0和I1，输出Y0和Y1。当A的信号强度<B时，输出Y0=15，Y1=0；A>B时，输出Y0=0，Y1=15；A=B时，输出Y0和Y1分别为I0和I1的放大值（非0即15）。
