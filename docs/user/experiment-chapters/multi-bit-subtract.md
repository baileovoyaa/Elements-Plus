> 前置章节：位运算器

前面我们学会了使用二进制表示数字，并进行了二进制数字的加法。本章我们要进行多位二进制数的减法。最直接的想法是像十进制竖式一样，从低位向高位逐位相减，不够减就向高位借 1，借 1 当 2。但计算机更擅长加法，单独设计一套减法电路并不划算。于是我们希望把减法也变成加法：`A − B = A + (−B)`。

问题于是变成：在只有 0 和 1 的固定位数中，怎样表示一个负数？答案就是——<font color="blue">补码</font>。

以 8 位二进制为例，一共有 2^8=256 个状态，从 00000000 到 11111111。我们可以把它们看成一个“模 256”的循环：11111111 再加 1，就回到 00000000。所谓 -x，就是找一个数，使得 `x + (-x) = 00000000`，并且丢弃最高位的进位。这个数就是 256-x。因为 `256 = 11111111 + 1`，所以 `256-x = (11111111-x)+1`。而 11111111-x 正好是把 x 的每一位都取反：0 变 1，1 变 0。因此得到补码的核心口诀：

**按位取反，末位加一。**

这就是 8 位二进制数求其相反数补码的取反逻辑。注意：全部 8 位都要参与取反；加 1 从最低位开始，逐位进位；如果最高位产生第 9 位进位，则直接丢弃。

例如，求 +10 的相反数 -10 的 8 位补码：

- +10 = 00001010
- 按位取反：11110101
- 末位加一：11110110

所以 -10 的 8 位补码是 11110110。验证一下：`00001010 + 11110110 = 1 00000000`

丢弃最高位进位，得到 00000000，正好是 0。

反过来，如果把 11110110 再取反加一：

- 取反：00001001
- 加一：00001010

又回到了 +10。这说明补码的“取反加一”是可逆的。正数的补码就是它本身，0 的补码也只有一种表示：00000000。

有了补码，多位减法就可以统一成多位加法。计算 A-B 时：

1. 把 A 和 B 都写成相同的 8 位；
2. 求 B 的相反数：对 B 全部 8 位取反，再末位加一，得到 -B；
3. 做普通二进制加法：A + (-B)；
4. 从最低位向最高位逐位相加，进位正常传递；
5. 丢弃最高位的进位；
6. 得到的结果就是 A-B 的补码。

例如计算 12-5：

- 12 = 00001100
- 5 = 00000101
- 对 5 取反加一：11111010 + 1 = 11111011，即 -5
- 相加：00001100 + 11111011 = 1 00000111
- 丢弃最高位进位，得到 00000111，即十进制 7。

再如计算 5-12：

- 12 = 00001100
- 对 12 取反加一：11110011 + 1 = 11110100，即 -12
- 相加：00000101 + 11110100 = 11111001
- 11111001 最高位是 1，表示负数。对它取反加一：00000110 + 1 = 00000111
- 得到 7，所以结果是 -7。

8 位补码能表示的范围是 -128 到 +127。最高位为 0 表示正数或 0，最高位为 1 表示负数。超出这个范围就会发生溢出，例如 127+1 得到 10000000，按 8 位补码读作 -128，而不是 +128。所以固定位数下还要注意溢出。

总之，补码把减法变成了加法：

`A-B = A + (~B + 1)`

其中 ~B 表示按位取反。多位减法不再需要单独的借位电路，只需逐位相加、传递进位，并丢弃最高位进位即可。这就是计算机用加法器完成减法的核心思想。
