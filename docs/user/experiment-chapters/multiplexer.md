> 前置章节：高级逻辑门

<font color=gold>多路选择器</font>可以在多条输入中选择一个作为输出，这在后面设计多功能运算器时很有帮助。

**注意**：由于这部分电路逻辑较复杂，信号强度难以保留，故下面的实验涉及的输入 D、D0、D1、D2、D3 都只考虑 0 和非 0 两种情况，非 0 即视为 15，而不是输出原始信号强度。下面称为“<font color=blue>放大值</font>”。

首先是 <font color=gold>2选1多路选择器</font>：输入 A、D0、D1，输入 A 为 0 时输出 Y 为 D0 的放大值，输入 A 为非 0 时输出 Y 为 D1 的放大值。

如果你还不清楚怎么做，可以想想，在我们做的<font color=blue>基础逻辑门</font>里，什么元件的作用最像一个“开关”？

```epp-experiments
2选1多路选择器
```

---

然后我们把输入扩展到 4 条，就有了 <font color=gold>4选1多路选择器</font>。

输入 A0、A1、D0、D1、D2、D3，输出 Y。

- 当 A1 为 0，A0 为 0 时，输出 D0 的放大值。
- 当 A1 为 0，A0 为非 0 时，输出 D1 的放大值。
- 当 A1 为非 0，A0 为 0 时，输出 D2 的放大值。
- 当 A1 为非 0，A0 为非 0 时，输出 D3 的放大值。

提示：四选一，就相当于先四选二再二选一。

```epp-experiments
4选1多路选择器
```

---

然后我们再堆叠 8 条线，就有了 <font color=gold>8位多路选择器</font>。它可以对<font color=blue>8位总线</font>进行选择。

还不了解<font color=blue>总线</font>的概念？可以先完成“<font color=gold>多位加法器</font>”章节后再来。

8 位多路选择器的特性和 1 位的一样，只是输入 D0~D3 和输出 Y 变成了 8 位。

```epp-experiments
2选1 8位多路选择器
4选1 8位多路选择器
```

---

还有一个比较实用的元件是“<font color=gold>8位三态缓冲器</font>”，它的作用类似开关，仅在“启用”时会输出信号，否则输出 0。因此通过这个元件可以轻松地将多个数据输出接到同一条共享总线上，只要确保任意时刻只有单个有效，数据就不会互相干扰。虽然使用开头所述的元件的 8 位运算对应版本也能实现，但稍微繁琐。封装为单个元件可以简化逻辑。

它有两个输入：使能输入 A 和数据输入 D，一个输出 Y。其中 D 和 Y 都是 8 位。当 A 为非 0 时，输出 Y 为 D 的放大值；当 A 为 0 时，输出 Y 为全 0。

```epp-experiments
8位三态缓冲器
```

---

另外或许你也想尝试能够保留原始信号强度的“<font color=gold>模拟多路选择器</font>”，这里作为可选实验留给你。完成“<font color=blue>基础逻辑门</font>”中的可选实验“<font color=gold>短路与</font>”和“<font color=gold>短路或</font>”后再做这个可能会更容易一些。

```epp-experiments
[OPTIONAL] 2选1模拟多路选择器
[OPTIONAL] 4选1模拟多路选择器
[OPTIONAL] 2选1 8位模拟多路选择器
[OPTIONAL] 4选1 8位模拟多路选择器
[OPTIONAL] 8位模拟三态缓冲器
```
