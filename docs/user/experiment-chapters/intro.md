# 电路实验

在这里你可以对你自制的电路进行测试，并逐步解锁各个高级元件

将你的电路图放入上方槽位，然后点击“开始实验”按钮，实验将会自动进行

实验成功后，你将获得一份编译过的电路图，它会关联一个元件，可以直接作为元件在光刻机中使用，也可以用于在光刻机“制造”标签页中制作芯片

注意：编译后的电路图将无法再进行编辑，但是你可以在光刻机制造页创建电路图的副本，取消勾选“保留编译状态”，副本不再拥有编译状态，可以继续编辑

如果实验失败，进度条会变成红色，悬停可查看具体失败原因。电路图的输入元件的状态会停留在失败的测例上，稍后你可以放到光刻机里查看具体失败逻辑。
