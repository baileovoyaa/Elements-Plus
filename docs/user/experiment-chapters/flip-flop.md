> 前置章节：多功能运算器（基础版）

接下来，我们将进入<font color=blue>时序逻辑电路</font>了。

前面我们做的是<font color=blue>组合逻辑电路</font>，还记得前面提到的概念吗：<font color=blue>组合逻辑电路</font>是一种输出仅依赖于当前输入状态、与电路过去状态无关的数字电路。

而<font color=blue>时序逻辑电路</font>则不一样。它的输出不仅取决于当时的输入信号，而且还取决于电路原来的状态，或者说，还与以前的输入有关。

时序逻辑电路的核心是<font color=blue>时钟</font>和<font color=blue>触发器</font>。时钟是电路时间的计量单位，一次时钟周期称为一个“tick（刻）”。而触发器则是一种在时钟边沿，根据上一个tick的输入来决定输出的元件。

为了实现这个，我们引入新的基本元件——<font color=gold>电容器</font>。它可以将输入的信号延迟1tick输出，从而实现信号的短暂保存。

电容器可以配置充电速度和放电速度，代表每tick信号强度的最大变化量。不过这个通常用于模拟电路。默认的充放电速度都是15，意味着信号会在1tick后立刻与输入信号保持一致，不会有任何过渡。

因此电容器本身就可以看作是一个触发器——它的输出取决于上一刻的输入。我们把这种触发器叫做“D触发器”。

我们来试着使用它。本次实验我们要做的是“<font color=gold>T触发器</font>”——

- <font color=gold>T触发器</font>：输入T，输出Q。当T为0时，在下一刻保持这一刻的输出，当T非0时，翻转输出（0或15）。或者说，当时钟步进时，若T为0，则输出保持不变，若T非0，则输出翻转。

```epp-experiments
T触发器
```

若输入一直非0，输出会在每一刻翻转，这正是预期的现象。

---

还有一种只会在输入信号从0变为非0时（上一刻为0，这一刻为非0）翻转输出。利用它可以做出类似切换开关的功能。它在红石电路中常被称作“T触发器”或“转换锁存器”，这里为了区分，我们把它称作“<font color=gold>T'触发器</font>”。

- <font color=gold>T'触发器</font>：输入C，输出Q。仅当这一刻C=1，上一刻C=0时，在下一刻翻转输出，否则保持输出。

```epp-experiments
[OPTIONAL] T'触发器
```
