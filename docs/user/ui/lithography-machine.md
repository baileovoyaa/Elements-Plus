# 光刻机

光刻机用于编辑电路图，并把电路图复制成新的电路图，或制造成带对应元件功能的芯片。

- **设计页**：放置元件、连接导线、配置元件参数、运行仿真。
- **制造页**：复制电路图，或用已编译的电路图制造芯片。

光刻机不会在世界上直接运行电路。设计页中的仿真是编辑器内的预览；电路图的实际使用方式是把它作为实验电路提交，然后把编译后的电路图制造成芯片后使用。

> 本页介绍光刻机界面本身的操作。实验桌、实验章节和电路图在实验中的使用方式，请参考[实验桌](experiment-table.md)。

## 打开与界面布局

使用光刻机方块打开界面。界面主要分为以下区域：

| 区域 | 说明 |
| --- | --- |
| 顶部标签页 | 切换**设计**页和**制造**页。 |
| 左侧元件列表 | 选择要放置的元件；也可以管理自己的元件分组。 |
| 中间画布 | 设计页显示电路图编辑区；制造页显示制造面板。 |
| 右上工具栏 | 设计页的仿真、导线、位宽、显示和检查工具。 |
| 右侧属性面板 | 设计页中显示当前选中元件的可配置项。 |
| 左下物品栏按钮 | 折叠或展开玩家物品栏，折叠后元件列表会获得更多高度。 |

设计页只显示上方的**电路图槽**。制造页会显示电路图槽、制造输入槽和输出槽三个槽位。

## 设计页

### 放入电路图

把 **[电路图](../items-and-blocks/misc.md#电路图)** 物品放入上方的电路图槽后，画布就会显示并在该物品中编辑电路图。

- 编辑结果会直接写入电路图物品。
- 没有放入电路图时，画布没有可编辑的内容。
- 画布的可编辑范围由电路图物品的规模决定；画布边缘会显示可用范围边框。
- 已经带有“已编译”状态或等效元件标记的电路图是只读的，详见[电路图状态](#电路图状态)一节。

### 元件列表

左侧元件列表用于取用元件，也可以像书签一样整理常用元件。

| 操作 | 效果 |
| --- | --- |
| 左键点击元件 | 选取该元件，进入放置模式。 |
| 鼠标悬停 | 显示元件名称；自定义元件还会显示描述、UUID 和作者等信息。 |
| 左键点击分组标题 | 展开或折叠分组。 |
| 右键点击自定义分组中的元件 | 删除这个元件条目；不会删除画布上已经放置的元件。 |
| 右键点击分组标题 | 打开分组菜单，可以插入新分组、重命名或删除自定义分组。 |
| 右键点击列表底部空白处 | 添加一个新的自定义分组。 |
| 拖动自定义分组中的元件 | 在自定义分组之间调整顺序。 |
| 拖动分组标题 | 调整分组顺序；列表靠近上下边缘时会自动滚动。 |
| 把带等效元件的物品（已编译电路图/芯片）拿在鼠标上，移到自定义分组的元件缝隙或列表底部后左键点击 | 把该元件加入元件列表，方便以后直接取用。 |

内置分组（例如“输入输出”“总线”）中的元件由模组提供，不能删除或改名。自定义分组可以自由添加、排序和删除。

要重复使用已经做好的电路，可以把它编译后的电路图或制造好的芯片拿在鼠标上，再加入自定义分组。具体条件见[电路图状态](#电路图状态)。

### 工具栏

工具栏只在设计页显示，从左到右依次为：

| 按钮 | 功能 |
| --- | --- |
| 播放/暂停 | 开始或暂停自动仿真。暂停后仍会保持组合逻辑的当前求值结果。 |
| 单步 | 暂停自动仿真，并推进一个仿真步。 |
| 复位 | 暂停仿真，并清除寄存器、计数器、RAM、电容等运行时状态，重新开始。 |
| 速度滑块与输入框 | 设置自动仿真的速度，范围 `1~20`，表示每秒推进的仿真步数。滑块和输入框会互相同步。 |
| 铜线 | 选择铜线，作为当前要绘制的新导线。 |
| 金线 | 选择金线，作为当前要绘制的新导线。 |
| 位宽数字 | 在 `1` 位和 `8` 位（总线）之间切换。点击按钮或在该按钮上滚动滚轮都可以切换。 |
| 明暗切换 | 在深色和浅色画布之间切换；设置会保存到客户端配置。 |
| 声音 | 开关界面操作音效；设置会保存到客户端配置。 |
| 总线数字格式 | 切换 8 位总线的显示格式：无符号、补码、十六进制。 |
| 信号强度格式 | 切换 1 位信号强度的显示格式：无符号、补码、十六进制。 |
| 检查模式 | 开启后，鼠标悬停在元件或导线上会显示详细运行信息。 |

数字格式按钮：**左键点击**循环到下一个格式，**Shift + 左键点击**循环到上一个格式。格式只影响界面显示，不会改变电路中的实际值。

位宽按钮决定接下来新绘制导线的位宽，不会批量修改已经画好的导线。用中键拾取已有导线时，会同时拾取它的位宽。

### 画布操作

确保当前没有选中的元件或导线工具时，才能直接选择和拖动已有内容。如果正在放置元件或导线，先按右键取消当前工具。

#### 鼠标操作

| 操作 | 效果 |
| --- | --- |
| 左键点击元件 | 选中该元件，并在右侧显示属性。 |
| 左键拖动空白处 | 框选。框中涉及的元件以及框内的导线会被选中。 |
| 左键拖动已选中的元件或导线 | 移动整个选中组。 |
| 先选中，再 `Ctrl` + 左键拖动 | 复制选中组。 |
| `Shift` + 拖动选中组 / `Ctrl` + `Shift` + 拖动选中组 | 移动或复制，并允许覆盖目标位置已有的内容。 |
| 在元件列表或已放置元件上选取元件后，左键点击画布 | 放置元件。放置模式会保持，可连续放置；右键取消。 |
| `Shift` + 左键点击放置 | 强制放置，允许覆盖目标格已有内容。 |
| 选择铜线/金线后，左键拖动 | 绘制一条按网格自动转折的导线。 |
| 选择铜线/金线后，`Ctrl` + 左键拖动 | 绘制直线导线。 |
| 右键 | 取消当前的元件/导线工具。没有工具时，删除鼠标下的元件或导线。 |
| 右键拖动 | 沿拖动路径连续删除。 |
| `Shift` + 右键点击或拖动导线 | 删除与鼠标所在导线连通的同材质、同一位宽整条线网。 |
| 中键点击元件或导线 | 拾取该元件或导线，作为新的放置模板。中键按下的位置会保留元件的朝向和镜像状态。 |
| 中键拖动 | 平移画布。拖动距离超过阈值时不会再触发拾取。 |
| 滚轮 | 平移画布。 |
| `Shift` + 滚轮 | 水平平移画布。 |
| `Ctrl` + 滚轮 | 以鼠标位置为中心缩放画布。 |
| `Alt` + 滚轮 | 旋转鼠标下的元件；如果正在放置元件，则旋转放置预览。 |

#### 键盘操作

| 按键 | 功能 |
| --- | --- |
| `Delete` | 删除当前选中的元件和导线；框选时删除框中的内容。 |
| `Ctrl` + `Z` | 撤销。 |
| `Ctrl` + `Shift` + `Z` 或 `Ctrl` + `Y` | 重做。 |
| `M` | 水平镜像当前选中或正在放置的元件。 |
| `N` | 垂直镜像当前选中或正在放置的元件。 |
| `Enter` | 提交右侧属性面板或对话框中的文字输入。 |
| `Esc` | 关闭右键菜单，或取消当前对话框。 |

`M` 和 `N` 是模组的按键绑定，可以在“选项 → 控制”中修改。输入框获得焦点时，删除、镜像等画布快捷键会让位给输入框。

#### 连线与位宽

- 铜线和金线是两种不同的导线材质，信号不能直接跨材质传输。
- `1` 位导线用于单个信号；`8` 位导线用于 8 位总线。
- 导线位宽不匹配时，画布会在连接位置显示位宽不匹配标记。常见原因是把 1 位导线接到了 8 位引脚，或把 8 位导线接到了 1 位引脚。
- 元件引脚可以和相邻元件的引脚直接对接，也可以先引出一段导线再连接。

### 元件配置

选中单个元件后，右侧属性面板会显示它的名称、图标和可配置项。

- 复选框：点击切换布尔选项。
- 滑块：按住左键拖动调整数值；松开后写入电路图。
- 文本框：编辑标签等文字，按 `Enter` 提交；关闭界面时也会自动提交。
- 多选时，属性面板只显示“已选中多个元件”，不会同时编辑多个元件的配置。

部分元件支持双击快速配置：

| 元件 | 双击效果 |
| --- | --- |
| 1 位输入 | 在 `0` 和 `15` 之间切换信号强度（低/高）。 |
| 8 位输入 | 打开 8 位数值输入框。 |
| 8 位常量 | 打开 8 位数值输入框。 |
| 8 位掩码 | 打开 8 位数值输入框。 |
| 8 位模拟常量 | 打开 8 个通道的强度编辑框。按高位到低位输入 8 个 `0~15` 的整数，用空格分隔。 |
| RAM | 打开 RAM 内容查看器。 |
| ROM | 打开 ROM 内容编辑器。 |

8 位数值输入框会按当前的总线数字格式显示和解析数值。只读电路图中仍然可以预览修改输入元件（1 位输入、8 位输入）的值并运行仿真，但这些改动不会写回电路图。

### ROM 编辑器

双击 ROM，或选中 ROM 后点击属性面板中的“编辑 ROM 内容”，打开 256 字节的 ROM 编辑框。

| 操作 | 效果 |
| --- | --- |
| 左键点击单元格 | 选中并开始编辑该字节。 |
| 左键拖动 | 按行优先顺序连续选择。 |
| 中键拖动 | 矩形选择。 |
| 方向键 | 在网格中移动当前单元格。 |
| `Tab` / 空格 | 移到下一个/上一个单元格；配合 `Shift` 反向移动。 |
| `Enter` | 移到下一行开头。 |
| `Delete` | 清除选中单元格的内容。 |
| `Ctrl` + `A` | 全选（正在编辑字节时需按两下）。 |
| `Ctrl` + `C` / `Ctrl` + `V` | 复制/粘贴选中的字节。 |
| `Ctrl` + `Z` / `Ctrl` + `Shift` + `Z` / `Ctrl` + `Y` | 撤销/重做。 |
| `Ctrl` + `Enter` | 保存并关闭。 |
| `Esc` | 取消并关闭。 |

RAM 打开的是只读查看器，用来观察内存内容和当前地址对应的数据；不能直接编辑。

### 仿真与检查

- **播放**：按设定速度持续推进仿真。检测到组合环路时会停止播放，并显示“检测到组合环路”提示。
- **单步**：只推进一个仿真步，适合观察寄存器、计数器、RAM 等时序元件的状态变化。
- **复位**：清除时序元件的运行时状态，让电路从初始状态重新开始。
- **暂停**：停止自动推进，但仍会对组合逻辑进行求值。修改输入、常量等配置后，结果会立即反映在画布上。

设计页中的仿真结果只用于编辑和检查，不会作为世界中的持久运行状态保存。

开启检查模式后，悬停在元件上可以看到：

- 元件名称、朝向和镜像状态；
- 输入/输出引脚及其当前信号值；
- 自定义元件的 UUID 和作者信息；
- 导线各通道的实时信号值。

## 制造页

制造页负责两类操作：**复制电路图**和**制造芯片**。两者使用同一组槽位，具体走哪条分支由电路图槽和制造输入槽的内容决定。

### 槽位

| 槽位 | 用途 |
| --- | --- |
| 电路图槽 | 放入作为模板或制造依据的电路图。 |
| 制造输入槽 | 复制时放入未编译的电路图；制造时放入空晶片或创造模式元件。 |
| 输出槽 | 显示复制出的电路图，或制造出的芯片。 |

取走输出时才会消耗输入槽和所需材料。模板槽中的电路图不会被消耗，可以继续用于下一次复制或制造。

### 复制电路图

把源电路图放入电路图槽，再把另一张**未编译、未带等效元件标记**的电路图放入制造输入槽，输出槽就会显示复制结果。

- 取走复制结果时，会消耗制造输入槽中的一张电路图。
- 源电路图保留，可以反复作为模板使用。
- 如果源电路图已编译，并且输入槽是未编译的电路图，界面会显示“复制编译状态”复选框。
  - 勾选（默认）：复制结果也保持编译状态，是只读的。
  - 取消勾选：复制结果为可编辑的电路图。
- 如果源电路图本身未编译，则直接复制其可编辑内容。

### 制造芯片

要制造芯片，需要同时满足以下条件：

1. 电路图槽中的电路图已经编译，并带有等效元件标记。
2. 制造输入槽中放入空晶片（小/中/大/巨大空晶片），或创造模式元件（若可用）。
3. 空晶片的规模不小于电路图的规模。
4. 普通空晶片还需要玩家物品栏中有足够的制造材料。

满足条件后，输出槽会显示带对应元件功能的芯片。制造页会列出所需的物品和元件芯片，并用“已有数量/所需数量”显示材料是否足够：

- 绿色：数量足够。
- 红色：数量不足。

空晶片有小型、中型、大型、巨型四种规模，分别覆盖 `32×32`、`64×64`、`128×128`、`256×256` 格。普通芯片的输出规模与放入的空晶片规模一致，因此可以用更大的空晶片制造较小规模的电路。

制造页没有足够的材料或条件不满足时，输出槽会为空，不会生成半成品。

取走产物时：

- 消耗制造输入槽中的一张输入物（空晶片或创造模式元件）；
- 普通空晶片还会按材料清单消耗玩家物品栏中的物品和元件芯片；
- 电路图模板保留；
- 普通芯片的输出规模与放入的空晶片规模一致。

使用创造模式元件时，不消耗制造材料，也不受电路图规模限制，但需要处于创造模式，或由服务器开启生存模式使用创造模式元件的配置。相关配置见[配置](../configs.md#服务端配置)。

### 关闭界面的注意事项

关闭光刻机界面时：

- 电路图槽和制造输入槽中的物品会退回玩家物品栏；空间不足时会掉落在附近。
- 输出槽中尚未取走的产物会被丢弃，以防止刷物品。

## 电路图状态

电路图物品有两种常见状态：

- **可编辑**：可以在设计页放置、移动、删除元件和导线，并保存修改。
- **已编译**：通常来自实验成功后的返回结果，或由复制时保留编译状态得到。已编译的电路图是只读的，不能在设计页修改结构。

已编译的电路图如果带有等效元件标记，就可以作为对应元件在电路图里放置，可以添加到元件列表，也可以在制造页作为制造芯片的模板。

### 使用编译后的电路图

1. 在元件列表中右键添加一个自定义分组（或使用已有自定义分组）。
2. 把编译后的电路图或对应芯片拿在鼠标上。
3. 把物品移到自定义分组的元件缝隙或列表底部空白处，左键点击加入元件列表。
4. 之后在元件列表中左键点击它，即可像普通元件一样放置。

### 想编辑已编译的电路图

已编译的电路图不能直接变回可编辑状态。可以在制造页复制一份，并在复制时取消“复制编译状态”，得到可编辑的副本。

## 常见问题

**画布不能编辑**

确认电路图槽中放入了电路图，并且该电路图不是已编译/带等效元件标记的只读电路图。只读电路图只能预览输入值，不能修改结构。

**放不下元件或导线**

画布有边界，元件和导线必须位于电路图规模允许的范围内。使用 `Shift` 放置或拖动可以覆盖已有内容，但不会突破边界。

**无法开始播放**

检查画布是否提示“检测到组合环路”。组合逻辑中存在环路时不能开始自动播放，需要调整电路或改用能打断环路的时序元件。

**制造页没有输出**

依次检查：

- 电路图是否已编译并带有等效元件标记；
- 制造输入槽是否放入了空晶片（复制分支则是未编译的电路图）；
- 芯片规模是否覆盖电路图规模；
- 材料数量是否全部为绿色；
- 是否把物品放到了正确的槽位。

**取走芯片后材料不够了**

制造取走时会从玩家物品栏扣除材料。若材料刚好够一次制造，取走后输出槽会清空；继续制造前需要补充材料。
