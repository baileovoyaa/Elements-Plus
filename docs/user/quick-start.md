## 银的获取与使用

银是一种稀有程度介于铁和金之间的金属，同时也是本模组的重要材料之一。

银的主要获取方式之一是通过在地下挖矿获得。

银矿会在Y=-44到Y=48之间呈三角分布，在Y=2处分布最多。

在之后的游戏中还可以通过使用金属催化器从64个玄武岩中提取1个银锭。

银的主要用途之一是制作扳手，扳手可以用于调整管道的方向和红石接口的配置。

银的另一个主要用途是制作银管，银管可以传递红石信号。

银管类似于钢管，可以直接跨层级传输，隔离不想要的信号传递，还可以控制信号的充能方向，但相比与钢管，银管的信号衰减更少。

## 紫水晶的获取与使用

紫水晶的主要获取方式之一是在地下生成的紫水晶洞中开采。与其他矿物不同的是，紫水晶是可以再生的。

在之后的游戏中还可以通过使用高压结晶器将沙子制成紫水晶碎片。

紫水晶在此模组中具有非常重要的作用，在之后的游戏流程中需要大量消耗。

紫水晶的主要用途之一是制作和加工晶圆。晶圆需要多个步骤的处理才能用于制作，不同的物品可能需要不同加工步骤的晶圆来制作。

紫水晶的另一个用途便是与粘液球合成绝缘层，绝缘层可以用于合成模组中的各种元件。部分元件的制作还会直接使用到紫水晶碎片。

紫水晶还可以与玻璃板合成紫水晶透镜，紫水晶透镜可以用于合成本模组中的机器。

紫水晶还可以用于合成电脑、显影槽等机器部件，部分机器的合成也会直接使用紫水晶碎片。
