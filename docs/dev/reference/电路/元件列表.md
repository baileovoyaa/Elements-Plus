> 此处方位词对应默认朝向，而不是旋转后的

### 晶体管

具有两个输入和一个输出，`输出 = min(floor(2 * 西输入 * (1 - 南输入 / 15)), 15)`

### 二极管

具有一个输入和一个输出，`输出 = 输入`

### 电阻

> 原先设计是倍率，但是考虑到 Minecraft 信号线性衰减的特性，同时为了规避浮点误差带来的麻烦，现改用线性衰减。

参数：衰减，整形，范围0~15，默认1

具有一个输入和一个输出，`输出 = max(输入 - 衰减, 0)`

### 电容

**时序元件**

具有一个输入和一个输出

参数：

- 充电速度（整形0~15，默认15）：当前输入大于当前输出时，下一刻输出应该增加的最大量（不会超过当前输入）
- 放电速度（整形0~15，默认15）：当前输入小于当前输出时，下一刻输出应该减小的最大量（不会低于当前输入）

最初输出为0，设下一刻输出为Q1，当前刻输入为D，当前刻输出为Q，则：

```
if (D > Q) {
    Q1 = min(Q + 充电速度, D)
} else if (D < Q) {
    Q1 = max(Q - 放电速度, D)
} else {
    Q1 = Q
} 
```

因此，当充放电速度都是15时，其作用相当于DFF，将输入延迟一刻输出

### 谐振器

具有一个输入和一个输出。

参数：

- 高电平保持（整形1~20，默认1）：保持输入信号强度的持续刻数
- 低电平保持（整形1~20，默认1）：保持0信号强度的持续刻数
- 初相（整形0~40，默认0）：从复位后开始模拟相当于从第几刻开始，影响最初处于高电平还是低电平，以及最初状态的持续时间

某一刻的输出取决于其所在的相位，只能是输入或0，一个周期=高电平保持+低电平保持

### 电池

具有一个输出

持续输出15信号（不可调节）

### 输入

具有一个输出

参数：虚拟输入信号（0~15，默认0）

作为外部输入源，在电路图中模拟时可以调节任意信号（0~15），双击元件可以在0和15之间快速切换（不为0则变成0，为0则变成15），同时在格子上显示当前输出强度的数字，覆盖在图标上方

### 输出

具有一个输入

输出到外部电路，在电路图中模拟时具有特殊渲染逻辑：在格子上显示当前输入强度的数字，覆盖在图标上方

### 8位输入输出

8位输入有1个标签属性和8个滑块属性（分别对应每一位的0~15信号强度），双击可以打开一个类似元件列表组重命名的对话框，输入框自动填入当前数字值，输入0~255的数字点确定后8个滑块设为对应二进制（1对应15，0对应0）

8位输出只有1个标签属性。

8位输入输出元件上显示的数字是0~255的数字，表示当前输入/输出二进制对应的十进制数。非0视为1，0视为0。数字文本颜色是8位总线色（0xFF00FF）。

同样，8位输入输出也要做好预检、测例适配和写回，预检时检查位宽（例如实验要求输入A是8位，但实际上持有标签A的是一个一位输入元件，则预检不通过）。
