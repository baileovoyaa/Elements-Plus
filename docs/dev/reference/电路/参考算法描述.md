## 核心算法简述

核心是一套「建图 → 排序 → 传播」的组合逻辑求值流程，加上对时序元件（触发器等）的时钟处理。

### 1. 导线网络合并（并查集）
所有 `wire` 格子只有四连通关系，用**并查集（带路径压缩）**把互相连通的导线合并成一个"网络节点"（net）。每个网络内部等价于一根理想导线（求值时做**线或**：如果有多个驱动源，取最大值，只要有一个驱动源为 1，整网为 1）。

### 2. 建立依赖图
节点分三类：
- **Net 节点**（导线网络）
- **Comb 节点**（与/或/非/与非/或非/输入/输出/高电平…）
- **DFF_Q 节点**（触发器的 Q 输出）

边表示信号流向：元件的输入引脚所连网络 → 元件节点 → 元件输出引脚所连网络。

关键点：**DFF 的 D 输入不建边**，只把它的 Q 输出接入组合图。这样时序环被自然"切断"，形成跨时钟周期的延迟，避免误判为组合环。

### 3. Kahn 拓扑排序
对依赖图做拓扑排序，得到合法的求值顺序，保证每个节点求值时其所有前驱（输入）已经算完。

### 4. Tarjan 求 SCC 检测组合环
若拓扑排序未能覆盖全部节点，说明存在环（纯组合反馈，如"非门输出接回自己输入"）。此时对未排序节点跑**迭代版 Tarjan 强连通分量**算法，把属于大小 >1 的 SCC 中的 Net 节点标记为 `badNet`，绘制时显示红色并弹出警告条。

### 5. 数值传播（求值）
按拓扑序单遍扫描所有节点：
- **Net**：线或（任一前驱为 1 → 1）
- **Comb**：按门类型计算（`and`/`or`/`not`/`nand`/`nor`，`input` 取 `cell.val`，`output` 透传，`high` 恒 1）
- **DFF_Q**：直接读取触发器内部状态 `state`

结果按格子 key 缓存到 `wireVal` / `compVal` 供绘制查询。

### 6. 时钟步进（时序语义）
`tick()` 实现**同步时序**：
1. 先用当前状态求值一次；
2. **采样**每个 DFF 的 D 输入（左邻网络的值）；
3. 边沿统一**更新**所有 DFF 的 `state`；
4. 若有状态变化则重新求值一次（模拟新状态对组合逻辑的影响）。

### 7. 缓存与增量
依赖图用 `cache` 缓存，`cacheDirty` 在编辑电路时置脏，只有真正需要时才 `rebuildCache()`（并查集 + 建边 + 拓扑排序 + SCC），避免每帧重复建图。

**整体流程：** 编辑 → 标脏 → 重建依赖图（并查集 / 拓扑 / SCC）→ 拓扑序传播求值 → 时钟沿统一更新触发器 → 渲染。
