# 8 位指令集

> 状态：设计参考，尚未实现。本文描述指令编码、汇编记法、握手和时序约定；后续实现以此为准，如有调整先改本文。

## 1. 概览

- 8 位定长指令，每条指令 1 字节。
- 8 位地址空间，共 256 字节。
- 4 个通用寄存器 `R0`~`R3`，外加一个独立的 8 位跳转目标寄存器 `TR`。
- 没有 HALT；程序用忙等待暂停。没有调用栈、进位标志和中断。
- 基础 ALU 只实现第一页；第二页保留给高级功能。

## 2. 寄存器与地址空间

| 编码 | 名称 | 读 | 写 |
| --- | --- | --- | --- |
| `00` | `R0` | 累加器 | ALU 结果、普通寄存器 |
| `01` | `R1` | 地址寄存器 | 地址寄存器 |
| `10` | `R2` | `mem[R1]` | `mem[R1]` |
| `11` | `R3` | `DI`（输入数据） | `DO`（输出数据） |

- `R2` 不是独立存储，而是 `mem[R1]` 的映射；读写 `R2` 就是读写 `R1` 指向的内存单元。
- `R3` 是唯一的 IO 寄存器：读 `R3` 表示从 `DI` 读入，写 `R3` 表示向 `DO` 写出。
- `TR`：8 位跳转目标寄存器，只能由 `SETTARGET` 写入；所有跳转都执行 `PC <- TR`。
- `PC`：8 位程序计数器，复位为 `0x00`；顺序执行时 `PC <- PC + 1`，溢出回绕到 `0x00`。
- 内存：`0x00`~`0xFF`，没有保护；未初始化内容按 `0x00`（NOP）处理。

## 3. 机器码格式

每条指令 8 位。操作数编码：

- `RR`、`SS`、`DD`：2 位寄存器编号，`00`=`R0`，`01`=`R1`，`10`=`R2`，`11`=`R3`。
- `nnnn`：4 位立即数。
- `CCCC`：4 位跳转条件码。

| 高 4 位 | 用途 |
| --- | --- |
| `0000` | `NOP` / 保留 |
| `0001` | 保留 |
| `0010` | ALU 第一页（`0010 0XXX`）；第二页保留（`0010 1XXX`） |
| `0011` | `MOV` |
| `01xx` | `LDL`（低 4 位立即数） |
| `10xx` | `LDH`（高 4 位立即数） |
| `1100` | 数据条件跳转 |
| `1101` | IO 条件跳转 |
| `1110` | `SETTARGET`（`1110 00RR`）；有符号比较跳转（`1110 01CC`） |
| `1111` | 保留 |

## 4. 指令集

### 4.1 数据传送与立即数

| 汇编 | 机器码 | 十六进制 | 语义 |
| --- | --- | --- | --- |
| `NOP` | `0000 0000` | `0x00` | 空操作，`PC <- PC + 1` |
| `LDL Rd, #n` | `01 RR nnnn` | `0x40`~`0x5F` | `Rd` 低 4 位 <- `n`；`Rd` 只能是 `R0`/`R1` |
| `LDH Rd, #n` | `10 RR nnnn` | `0x80`~`0x9F` | `Rd` 高 4 位 <- `n`；`Rd` 只能是 `R0`/`R1` |
| `MOV D, S` | `0011 SS DD` | `0x30`~`0x3F` | `D <- S`，IO 规则见 §6 |
| `SETTARGET Rs` | `1110 00RR` | `0xE0`~`0xE2` | `TR <- Rs`；`Rs` 只能是 `R0`/`R1`/`R2` |

`LDL`/`LDH` 的合法范围：

- `LDL R0`：`0x40`~`0x4F`；`LDL R1`：`0x50`~`0x5F`。
- `LDH R0`：`0x80`~`0x8F`；`LDH R1`：`0x90`~`0x9F`。
- `Rd` 为 `R2`/`R3` 的编码保留，基础版按 NOP 执行；这样不会出现半个字节写内存/IO 的副作用。

`SETTARGET` 的合法范围：

- `SETTARGET R0`：`0xE0`；`SETTARGET R1`：`0xE1`；`SETTARGET R2`：`0xE2`（读取 `mem[R1]`，不读 IO）。
- `SETTARGET R3`：`0xE3` 保留，基础版按 NOP 执行，避免误触发输入读取。
- 机器码只有 `SETTARGET Rs`；`SETTARGET #imm8` 是汇编伪指令，见 §5.2。

`MOV` 采用“汇编写目标、机器码先源后目标”的形式：

```text
MOV D, S  ->  0011 SS DD
```

全部 16 种组合：

| 源 \ 目标 | `R0` (`00`) | `R1` (`01`) | `R2` (`10`) | `R3` (`11`) |
| --- | --- | --- | --- | --- |
| `R0` (`00`) | `0x30` NOP | `0x31` `R1<-R0` | `0x32` `[R1]<-R0` | `0x33` `DO<-R0` |
| `R1` (`01`) | `0x34` `R0<-R1` | `0x35` NOP | `0x36` `[R1]<-R1` | `0x37` `DO<-R1` |
| `R2` (`10`) | `0x38` `R0<-[R1]` | `0x39` `R1<-[R1]` | `0x3A` NOP | `0x3B` `DO<-[R1]` |
| `R3` (`11`) | `0x3C` `R0<-DI` | `0x3D` `R1<-DI` | `0x3E` `[R1]<-DI` | `0x3F` `DI->DO` |

### 4.2 ALU

基础版只实现 `0010 0XXX` 这一页：

| 汇编 | 机器码 | 十六进制 | 语义 |
| --- | --- | --- | --- |
| `ADD` | `0010 0000` | `0x20` | `R0 <- R0 + mem[R1]`，8 位回绕 |
| `SUB` | `0010 0001` | `0x21` | `R0 <- R0 - mem[R1]`，8 位回绕 |
| `AND` | `0010 0010` | `0x22` | `R0 <- R0 & mem[R1]` |
| `OR` | `0010 0011` | `0x23` | `R0 <- R0 \| mem[R1]` |
| `NOT` | `0010 0100` | `0x24` | `R0 <- ~R0`，不访问内存 |
| `XOR` | `0010 0101` | `0x25` | `R0 <- R0 ^ mem[R1]` |
| `SHL` | `0010 0110` | `0x26` | `R0 <- R0 << (mem[R1] & 0x07)`，逻辑左移 |
| `SHR` | `0010 0111` | `0x27` | `R0 <- R0 >> (mem[R1] & 0x07)`，逻辑右移 |

- ALU 操作数固定为 `R0` 和 `mem[R1]`，结果固定写回 `R0`；内存不变。
- `NOT` 是单目运算，忽略 `mem[R1]`，也不产生内存读。
- `SHL`/`SHR` 的移位量取 `mem[R1]` 的低 3 位，范围 0~7；移出的位舍弃，空缺位补 0。
- 加减法按 8 位回绕，不保留进位/借位，也没有 flags。
- `0010 1XXX`（`0x28`~`0x2F`）保留给高级 ALU；基础版按 NOP 执行。

### 4.3 跳转与目标寄存器

所有跳转都跳转到 `TR`：

```text
if condition: PC <- TR
else:         PC <- PC + 1
```

| 汇编 | 机器码 | 十六进制 | 条件 |
| --- | --- | --- | --- |
| `JMP` | `1100 0000` | `0xC0` | 无条件 |
| `JZ` | `1100 0001` | `0xC1` | `R0 == 0` |
| `JN` | `1100 0010` | `0xC2` | `R0 < 0`（有符号） |
| `JP` | `1100 0011` | `0xC3` | `R0 > 0`（有符号） |
| `JEQ` | `1100 0100` | `0xC4` | `R0 == mem[R1]` |
| `JLT.U` | `1100 0101` | `0xC5` | `R0 < mem[R1]`（无符号） |
| `JGT.U` | `1100 0110` | `0xC6` | `R0 > mem[R1]`（无符号） |
| `JNZ` | `1100 1001` | `0xC9` | `R0 != 0` |
| `JNN` | `1100 1010` | `0xCA` | `R0 >= 0`（有符号） |
| `JNP` | `1100 1011` | `0xCB` | `R0 <= 0`（有符号） |
| `JNE` | `1100 1100` | `0xCC` | `R0 != mem[R1]` |
| `JGE.U` | `1100 1101` | `0xCD` | `R0 >= mem[R1]`（无符号） |
| `JLE.U` | `1100 1110` | `0xCE` | `R0 <= mem[R1]`（无符号） |
| `JLT` | `1110 0100` | `0xE4` | `R0 < mem[R1]`（有符号） |
| `JGT` | `1110 0101` | `0xE5` | `R0 > mem[R1]`（有符号） |
| `JGE` | `1110 0110` | `0xE6` | `R0 >= mem[R1]`（有符号） |
| `JLE` | `1110 0111` | `0xE7` | `R0 <= mem[R1]`（有符号） |
| `JVI` | `1101 0000` | `0xD0` | `VI == 1` |
| `JVO` | `1101 0001` | `0xD1` | `VO == 1` |
| `JNVI` | `1101 1000` | `0xD8` | `VI == 0` |
| `JNVO` | `1101 1001` | `0xD9` | `VO == 0` |

- `JN`/`JP`/`JNN`/`JNP` 把 `R0` 按 8 位补码解释，只与 0 比较。
- `JEQ`/`JNE` 是相等比较；`JLT.U`/`JGT.U`/`JGE.U`/`JLE.U` 与内存的大小比较按**无符号** 8 位解释。
- `JLT`/`JGT`/`JGE`/`JLE` 与内存的大小比较按**有符号补码**解释。实现时可以这样判断：符号位不同时，负数较小；符号位相同时，直接按无符号比较。
- `JVI`/`JNVI` 采样 `VI`，`JVO`/`JNVO` 采样 `VO`，用于轮询输入/输出握手。
- 条件在跳转指令执行阶段采样；与跳转同拍发生的输出握手/清 `VO` 不改变本条跳转已经采样到的值。
- 机器码中的跳转都无操作数，目标来自 `TR`；`JMP #label` 是汇编伪指令，见 §5.2。

### 4.4 保留编码

基础版把所有保留编码按 NOP 执行，便于以后扩展；程序不应依赖保留编码的 NOP 行为。

- `0x01`~`0x1F`：保留。
- `0x28`~`0x2F`：ALU 第二页保留。
- `0x60`~`0x7F`：`LDL` 的 `R2`/`R3` 保留。
- `0xA0`~`0xBF`：`LDH` 的 `R2`/`R3` 保留。
- `0xC7`、`0xC8`、`0xCF`：保留。
- `0xD2`~`0xD7`、`0xDA`~`0xDF`：保留。
- `0xE3`：`SETTARGET R3` 保留。
- `0xE8`~`0xEF`、`0xF0`~`0xFF`：保留。

## 5. 汇编记法

### 5.1 基本语法

- 每行一条指令，可以带标签和注释。
- 注释用 `;`。
- 标签写成 `name:`，可单独占一行。
- 寄存器写 `R0`~`R3`。
- 4 位立即数写 `#0x0`~`#0xF`；8 位立即数写 `#0x00`~`#0xFF`。
- `MOV` 写作 `MOV D, S`，目标在前、源在后；机器码中先编码源 `SS`，再编码目标 `DD`。

### 5.2 伪指令

伪指令会展开成多条机器指令，不属于 ISA 的单条编码。

| 伪指令 | 展开 | 说明 |
| --- | --- | --- |
| `LDI Rd, #imm8` | `LDL Rd, #lo`；`LDH Rd, #hi` | `Rd` 只能是 `R0`/`R1`；`lo = imm8 & 0xF`，`hi = (imm8 >> 4) & 0xF` |
| `SETTARGET #imm8` | `LDI R0, #imm8`；`SETTARGET R0` | 会覆盖 `R0` |
| `JMP #label` | `SETTARGET #label`；`JMP` | 会覆盖 `R0` |

- 不提供 `Jcc #label` 宏：设置目标会覆盖 `R0`，而条件通常也依赖 `R0`。需要带标签的条件跳转时，先用 `SETTARGET` 设好目标，再计算/装入 `R0`，最后执行 `Jcc`。
- 如果不想覆盖 `R0`，可以手动把目标装进 `R1`，再用 `SETTARGET R1`；但要自行保存 `R1` 原来的地址。

### 5.3 汇编到机器码示例

```asm
LDI R1, #0x10
```

展开为：

```asm
LDL R1, #0x0    ; 01 01 0000 = 0x50
LDH R1, #0x1    ; 10 01 0001 = 0x91
```

其他常用编码：

```text
SETTARGET R0    1110 0000 = 0xE0
JMP             1100 0000 = 0xC0
JZ              1100 0001 = 0xC1
JNVI            1101 1000 = 0xD8
JVO             1101 0001 = 0xD1
JLT             1110 0100 = 0xE4
JGT             1110 0101 = 0xE5
MOV R2, R3      0011 1110 = 0x3E
MOV R0, R3      0011 1100 = 0x3C
MOV R3, R2      0011 1011 = 0x3B
ADD             0010 0000 = 0x20
```

## 6. 时序与握手

### 6.1 指令退休

- CPU 可以是多周期实现；本文只规定架构效果，不规定每条指令占几个 tick。目前的指令基本都可以在 1 tick 内完成。
- 指令在退休时钟沿写寄存器/内存/`TR`，结果在**下一 tick**可见。
- 顺序执行时 `PC <- PC + 1`；跳转时 `PC <- TR`。
- `SETTARGET` 写入的 `TR` 在下一 tick 可见；紧跟其后的跳转使用新的 `TR`。

### 6.2 输入读

对 `MOV dst, R3`（源为 `R3`，且 `dst != R3`）：

- 在读阶段采样 `VI`。
- `VI=0`：忽略这次读；不拉 `RI`，目标不变。
- `VI=1`：拉高 `RI` **恰好一个 tick**，在该 tick 采样 `DI`；目标在退休时更新，下一 tick 可见。
- `RI` 与 `VI` 同时为 1 的那一拍就是输入传输拍；外部在传输后才更换 `DI`。

### 6.3 输出写与握手

对 `MOV R3, src`（目标为 `R3`，且 `src != R3`）：

- 定义 `VO` 阻塞：`VO=1 && RO=0`。
- 写阶段采样 `VO`/`RO`：
  - `VO=1 && RO=0`：输出阻塞，**忽略这次写**；`DO`/`VO` 不变，也不产生 pending。
  - `VO=1 && RO=1`：握手/清 `VO` 优先；本次写被接受，但作为 pending，**下一 tick** 才生效。
  - `VO=0`：接受写，作为 pending，下一 tick 生效。
- pending 写在本 tick 的时钟沿、握手/清 `VO` 之后应用，下一 tick 可见；因此不会覆盖正在被 `RO` 取走的 `DO`。
- 如果写被忽略，程序应通过 `JVO`/`JNVO` 轮询 `VO` 后重试。
- `RO` 由输出寄存器直接处理，不需要指令；`JVO`/`JNVO` 只观察 `VO`。

### 6.4 IO 到 IO

`MOV R3, R3` 表示输入直接写入输出，不经过 `R0`：

- `VI=0` 或输出阻塞（`VO=1 && RO=0`）：整条指令忽略；不拉 `RI`，不产生 pending，`DO`/`VO` 不变。
- `VI=1` 且输出不阻塞：采样 `DI`，拉 `RI` 一个 tick，并把 `DI` 作为 pending `DO`；下一 tick 起 `DO=DI`、`VO=1`。
- 如果同一 tick 发生 `VO && RO` 握手，清 `VO` 优先；新的 `DO`/`VO` 仍在下一 tick 生效。
- 这条指令只搬运数据，不改变 `R0`~`R2`。
- `MOV R3, R3` 在 IO 阶段开始时同时采样 `VI`、`VO`、`RO`，用同一组采样值决定是否读/写；阶段中途的变化不改变本次判断。

### 6.5 跳转条件采样

- 跳转条件在跳转指令的执行阶段采样。
- `JVO`/`JNVO` 采样的是采样时刻的 `VO`；如果同拍 `RO=1` 并发生握手，`VO` 可能在时钟沿被清掉，但本条跳转仍使用清掉之前的值。
- `JVI`/`JNVI` 同理，使用执行阶段采样到的 `VI`。
- `JZ`/`JN`/`JP` 等使用执行阶段的 `R0`；`JEQ`/`JLT.U`/`JLT` 等使用执行阶段的 `mem[R1]`。

### 6.6 复位与暂停

- 复位：`PC=0x00`，`R0`~`R3=0`，`TR=0x00`，`VO=0`，输出 pending 清零。
- 内存内容由加载器/测试系统写入；未初始化按 `0x00`（NOP）处理。
- 没有 HALT。暂停用忙等待实现：

```asm
halt:
    JMP             ; TR 必须已经指向 halt
```

设置 `TR` 后进入忙等待：

```asm
    SETTARGET #halt
halt:
    JMP
```

`SETTARGET #halt` 是伪指令，会覆盖 `R0`；如果 `R0` 还有用，先保存。

## 7. 算术语义

- `ADD`：`R0 <- (R0 + mem[R1]) & 0xFF`。
- `SUB`：`R0 <- (R0 - mem[R1]) & 0xFF`。
- `AND`/`OR`/`XOR`：按位运算，结果 8 位。
- `NOT`：`R0 <- (~R0) & 0xFF`，不访问内存。
- `SHL`/`SHR`：移位量 `n = mem[R1] & 0x07`；逻辑移位，空缺位补 0，移出位舍弃。
- 加减溢出按 8 位回绕，没有进位/借位标志；条件跳转直接比较 `R0` 和 `mem[R1]`，不依赖 flags。
- 与 0 的大小/符号判断按有符号补码；与内存的 `JLT.U`/`JGT.U`/`JGE.U`/`JLE.U` 按无符号 8 位，`JLT`/`JGT`/`JGE`/`JLE` 按有符号补码 8 位。

## 8. A+B 示例

下面的程序读两个输入，相加后输出，然后回到开头继续处理下一组。`R1=0x80` 用作暂存第一个输入的内存地址；程序代码应避免占用 `0x80`。

```asm
start:
    LDI R1, #0x80

    ; 等第一个 VI
    SETTARGET #wait1
wait1:
    JNVI
    MOV R2, R3          ; [0x80] <- DI，RI 一个 tick

    ; 等第二个 VI
    SETTARGET #wait2
wait2:
    JNVI
    MOV R0, R3          ; R0 <- DI，RI 一个 tick
    ADD                 ; R0 <- R0 + [0x80]
    MOV R2, R0          ; [0x80] <- sum

    ; 等输出空闲
    SETTARGET #waitout
waitout:
    JVO
    MOV R3, R2          ; DO <- sum，下一 tick 生效

    ; 回到 start
    JMP #start
```

说明：

- `SETTARGET #label` 和 `JMP #label` 是伪指令，会覆盖 `R0`；示例中都在数据已经存入内存之后使用。
- `JNVI` 在 `VI=0` 时跳回 `wait1`/`wait2`；`JVO` 在 `VO=1` 时跳回 `waitout`/`waitdone`。
- `MOV R3, R2` 的写请求在下一 tick 才成为可见的 `DO`/`VO`；后面的 `SETTARGET`/`JVO` 给了它足够的时间。
- 如果 `RO` 一直为 0，`JVO` 会一直循环等待；如果 `RO` 取走输出，`VO` 被清掉，循环退出。

## 9. 设计取舍

- **跳转目标独立成 `TR`**：避免“比较操作数”和“跳转目标”共用 `mem[R1]` 的冲突；所有跳转统一 `PC <- TR`。
- **半字节立即数只允许 `R0`/`R1`**：避免对内存做读-改-写、对 IO 做半个字节的写，也避免 `VO`/`RI` 的意外触发。
- **VI 无效或输出阻塞时忽略读写**：让轮询语义简单；程序用 `JVI`/`JVO` 等指令等待，不需要额外的异常机制。
- **有符号/无符号比较并存**：`JLT.U` 等按无符号，`JLT` 等按补码有符号；比较器只需增加符号位判断和一个选择，不增加指令周期。
- **IO 到 IO 直接搬运**：`MOV R3, R3` 一条指令完成输入到输出的直通，不占用通用寄存器。
- **输出握手优先、新写下一 tick 生效**：避免 `RO` 正在取走旧 `DO` 时被新值覆盖；写被阻塞时直接忽略，由程序轮询重试。
- **没有 HALT**：当前电路和 IO 接口是固定时钟频率，用忙等待即可；NOP 用于填充和对齐。
- **ALU 第二页保留**：基础版只实现第一页，`0010 1XXX` 留给后续的 INC/DEC/ASR 等高级功能。

## 10. 后续扩展

- ALU 第二页：`INC`/`DEC`、算术右移 `ASR`、取负 `NEG` 等。
- IO 端口扩展：当前只有 `R3` 一个 IO 寄存器；后续可考虑 IO 端口号或内存映射 IO。
- 调用/返回和栈：当前没有 CALL/RET；需要时再扩展，不影响现有编码。
- 汇编器：实现标签解析、`LDI`/`SETTARGET`/`JMP` 伪指令展开，以及保留编码检查。
