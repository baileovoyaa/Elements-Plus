> 设计阶段

```
容器接口
可编程6面访问
接口内部有9个槽位：IS、电路、电池、6 个磁盘
本质是红石接口的升级版，增加了容器访问能力，但是要求必须实现 6 个架构引脚（VI/RI/DI/VO/RO/DO，接口内部处理，不对外暴露）
接口槽位IS、容器指针CP（0~7）、槽位指针SP（0~255）、结果缓冲区、短参数寄存器ARGI（整数）、长参数存储器ARGS（字符串）、组件迭代器
NOP 无操作
SLOT.SET 设置槽位指针（ARGI）
SLOT.GET 读取槽位指针
SLOT.EXISTS 检查槽位是否存在
SLOT.INC 槽位指针+1
SLOT.DEC 槽位指针-1
SLOT.SWAP 将容器接口槽位IS和指针SP指向槽位交换
SLOT.MERGE 将IS和SP合并（若相同物品可以）
SLOT.INTERACT 如果可合并则合并，否则交换（类似鼠标左键点击）
SLOT.TAKE 从槽位中取出指定数量物品（ARGI）
SLOT.PUT 放指定数量物品到槽位（ARGI）
SLOT.DROP 丢弃指向槽位物品
IS.DROP 丢弃容器接口槽位物品
READ.ID 读取SP指向物品字符串id
READ.NAME 读取物品自定义名称（没有的返回空串）
READ.COUNT 读取物品数量
READ.STACKSIZE 读取物品堆叠数量
READ.DAMAGE 读取物品耐久度（若有）
READ.COLOR 读取物品颜色值（针对染色物品，0~15，若有）
CONT.SET #imm3 设置容器指针CP（0~5是6个面，6是自己，7保留（始终不存在））
CONT.GET 读取容器指针
CONT.INSERT 快速移动槽位物品（IS）到容器（与SP无关）
CONT.COLLECT 从容器中收集同种物品到IS（与SP无关），类似鼠标双击。IS无物品时收集与第一个有物品的槽位相同的物品
CONT.EXISTS 检查容器是否存在
CONT.SIZE 获取容器槽位数
CONT.FIND 查找某个物品从SP开始下一次出现的槽位（使用物品字符串id），并移动SP
COMP.SIZE 获取长参数存储器ARGS对应路径的组件大小（复合标签键数/列表长度/字符串长度/整数字节数/浮点数字节数）
COMP.TYPE 获取组件类型（整数/浮点数/字符串/列表/复合标签）
COMP.ITER 开始迭代当前组件（列表/复合标签）
COMP.NEXT 读取下一个迭代值
COMP.READ 读取值（整数/浮点数/字符串）
COMP.DUMP 以SNBT格式读取整个值（任意类型）
ARGI.LDI 下一个字节写入短参数寄存器ARGI
ARGI.INC 短参数寄存器+1
ARGI.DEC 短参数寄存器-1
ARGI.GET 读取短参数寄存器
ARGS.LDS 开始写入串，下一个字节是串长度n，后续n字节是串内容
ARGS.APPEND 追加串，下一个字节是串长度n，后续n字节是串内容
ARGS.GET 读取串
BUFFER.STASH.PUSH 暂存并清空结果缓冲区
BUFFER.STASH.POP 弹出暂存的缓冲区
BUFFER.STASH.SIZE 缓冲暂存区字节数
BUFFER.DROP 清空缓冲区
数据回传格式：
[类型][长度][数据]
其中“类型”占1字节，“长度”无符号占2字节（大端序），“数据”占“长度”字节，如果数据是长整数，采用大端序，如果是字符串，采用UTF-8编码。
“类型”为0xFF代表返回值，后面直接跟1字节错误码
- 0x00: 成功
- 0x01: 操作已尝试执行，但无实际效果（如CONT.INSERT但容器满）
- 0x10: ARGS满
- 0x20: NBT路径无法解析
- 0x21: NBT路径不存在
- 0x22: 超出读取长度限制
- 0x23: COMP.READ读到复合标签/列表
- 0x24: 迭代终止
- 0x30: 槽位不可放入或物品不兼容
- 0x31: 槽位不可取出或物品不兼容
- 0x32: 找不到该物品
- 0x40: 槽位不存在
- 0x41: 容器不存在
- 0x50: 未知 opcode
- 0x51: 权限问题（特定模组通过扩展支持）
其余的类型和指令操作码保持一致，根据指令推断数据类型，对于COMP.READ，建议先使用COMP.TYPE获取组件类型。
大部分指令都回传1个值，可能另外带有一个错误码（在数据前）。例如FF 00 01 00 01 10（错误码0，表示成功，操作码0x01，数据1个字节，0x10）
额外说明：
- RO=1 表示接口可以接收下一个命令字节，RO=0 表示忙/缓冲满；
- ARGS.LDS/ARGS.APPEND一次写入最多255字节，如果需要更长，需要多次写入
- ARGS容量默认1KB，服务端配置可调，满后ARGS.APPEND会失败
- 多字节指令在数据收齐后才执行
- 溢出、截断、未知 opcode 时返回错误
- BUFFER.STASH.*这类指令在结果缓冲区满时仍可执行
- SLOT.INC/DEC本身可越界，8位回绕，需要结合CONT.SIZE自行判断
- SLOT.TAKE/PUT 的 ARGI=0 表示不移动，数量超过槽位容量/堆叠上限时部分移动
- SLOT.DROP/IS.DROP以物品实体形式掉落
- 结果缓冲区有数据时VI为1
- 磁盘本身支持热插拔，因此接口弹出自己的磁盘是被允许的，合理利用还能实现一些高速数据交换。但是接口弹出自己的电路或电池会导致中断，需要其他容器接口来接管处理，并由后面的交互接口来自动化重新启动容器接口。
- BUFFER.STASH只有一个暂存区，新的PUSH会覆盖旧的，PUSH会清VI，POP也会恢复VI。
- 每个容器接口的电路是独立的，如果需要一个中央控制器来管理多个容器接口，需要自行连接和通信。
- 改变CP不会重置或钳制SP，SP保持不变且可能越界（试图越界操作会产生0x40错误码）
- COMP.* 操作的是SP指向的物品，如果想操作IS可以改变SP和CP使其指向IS，ARGS解析为NBT路径
```
