## 根

4 个根：

- `external`：外接设备
- `memory`：实验桌内存
- `shared`：共享空间
- `client`：客户端

## 路径格式

```
xxx, ./xxx 相对路径（当前目录）
../xxx 相对路径（上一级目录）
/xxx 绝对路径（同根）
client:/xxx 跨根（第一个/可省略）
```

`shared` 是平铺文件系统（无子目录），`external` 可能是（取决于介质），

当 `external` 是单文件时也可以直接用 `external:*` 来代表该文件
