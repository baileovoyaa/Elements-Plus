客户端第一次打开光刻机界面时默认显示（看是否已关闭过，点击按钮关闭帮助页面视为已关闭过，如果没有关闭是直接退的光刻机界面则不算已关闭过。状态写入客户端配置）

帮助页面打开后：

显示类似对话框的黑色背景

在屏幕中间显示图片画廊（用 `textures/gui/lithography_machine/gallery` 里的几张图，后面会扩充，目前只有3张，顺序按 `intro` → `put_circuit` → `to_be_continued`），需要等比约束图片宽高，而不是使用原像素尺寸

左侧和右侧按钮（“<”、“>”），可以切换图片

底部有两个按钮“查看完整文档”和“关闭”

“查看完整文档”链接到 `https://baileovoyaa.github.io/Elements-Plus/user/ui/lithography-machine.html`

在光刻机设计页工具栏，检查按钮的右边添加帮助按钮（用 `textures/gui/help.png`），点击可以再次打开帮助页面
