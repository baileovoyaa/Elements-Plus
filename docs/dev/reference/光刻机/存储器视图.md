RAM的内容查看：双击任意RAM元件，打开对话框，网格、行优先展示每个字节的数据（一个字节一个数，不显示每条通道的值），每行开头有灰色行首地址（从0开始），每个字节的值和行首地址的格式都跟随总线数字格式。当前地址输入（D）对应的数据格有黄底高亮。

ROM是组合逻辑元件（无状态），携带一个256字节属性，在属性面板只展示一个打开编辑对话框的按钮，点击按钮或双击元件打开编辑对话框：

- 展示方式和RAM类似
- 点击数字可以编辑
- **键盘按键**：按tab/空格键跳到下一个（若行尾则换行），shift+tab跳到上一个（行首则换行），按enter跳到下一行开头，↑/↓可在同一列上下移动，跳到新格时自动选中该格数字
- **连续输入**：数字格式为十六进制时，输入一个16进制数（如0F）后自动跳到下一个，从而可以连续输入
- **多选与复制**：鼠标拖动可以选中多格（显示为蓝底白字），按Ctrl+C可以复制为空格分隔的值，多选时不能输入数字，但是可以按Delete全部清零。按Ctrl+A全选（仅限非输入状态，输入状态按Ctrl+A先选中当前格数字，再按一次才选中所有格）。
- **粘贴**：按Ctrl+V粘贴时如果剪贴板上是单独的数字，如果正在编辑单个格，保持默认的粘贴行为，如果选择了多格，每一格都设为该数字；如果剪贴板上是空格分隔的值，从选中的格或多选时的第一格开始应用，和选择范围无关，粘贴后自动选中所有已粘贴的数据格。剪贴板内容的格式不正确时不进行粘贴。
- **撤销与重做**：编辑对话框有单独的撤销和重做。输入完成一个数字、一次粘贴为一次原子操作，和电路图独立，编辑完成（点击确定按钮应用）视为一次电路图原子操作。
- 从磁盘复制数据的功能暂时不做
- 有取消或确定按钮，按Esc取消（放弃更改），按Ctrl+Enter保存并关闭对话框。

## ROM行视图

ROM编辑对话框右上角“切换行视图”（对应是“切换网格视图”）

行视图下，内容显示为一个256行的表格

列分别是地址、数值（可编辑，对应网格视图中的一个格子）、汇编

汇编不能直接编辑，是根据数值解析的

表格可滚动

支持多选（连续选择）、全选、复制粘贴、16进制连续输入、撤销重做，行为和表格视图类似（不再有中键矩形选择，中键和左键行为一致）

对应输入地址的行高亮

由于表格较长，拖动多选时拖到表格下方时向下缓慢滚动，向上同理
