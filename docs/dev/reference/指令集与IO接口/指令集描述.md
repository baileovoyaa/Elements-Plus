## 指令集描述格式

```
; my_custom_isa.eppisa
#word 8
#endian msb

; 寄存器表
reg R0 = 0, R1 = 1, R2 = 2, R3 = 3

; ========== 真实指令 ==========
; 语法： <助记符> <操作数语法> = <每个字的位模板，多字用 '~' 分隔>
; 位模板中：0/1 是固定位，{name:w} 是宽 w 的字段切片，_ 只是视觉分隔

LDL  R{r:2}, #{v:4}   = 01_{r:2}_{v:4}
LDH  R{r:2}, #{v:4}   = 10_{r:2}_{v:4}
MOV  R{d:2}, R{s:2}   = 00_11_{s:2}_{d:2}

; ========== 伪指令 ==========
; 语法： .pseudo <语法> => <展开序列>
.pseudo LDI R{r}, #{v:8} =>
    LDL R{r}, #(v & 0xF)
    LDH R{r}, #((v >> 4) & 0xF)
```

## 指定指令集

内置指令集使用 `<...>`，自定义指令集使用[文件路径](../文件系统/路径.md)（可加引号）。默认是 `<epp-8-basic>`。

### 内置指令集

```
; isa=<epp-8-basic>
; isa=<epp-8-advanced>
; isa=<epp-16>
```

### 文件路径

```
; isa=my_custom_isa.eppisa
; isa=/isa/my_custom_isa.eppisa
; isa=client:/isa/my_custom_isa.eppisa
; isa=memory:/isa/my_custom_isa.eppisa
; isa=external:my_custom_isa.eppisa
```

### 扩展

```
; isa=<epp-8-basic>, “client:/isa/my_custom_isa.eppisa”
```

## 接口指令集与元编程

```
; interface=<container>
```

指定后，指令中可以使用接口操作码作为立即数，为了与标签区分，使用 `$` 作为前缀，例如

```
; isa=<epp-8-basic>
; interface=<container>

start:
    LDI R0, $(ARGI.LDI #0x08)[0]
    MOV R3, R0
    LDI R0, $(ARGI.LDI #0x08)[1]
    MOV R3, R0
    LDI R0, $SLOT.SET
    MOV R3, R0
    LDI R0, $SLOT.DROP
    MOV R3, R0
    JMP #start
```

对于上面的程序，由于 `<epp-8-basic>` 架构的 `LDI` 伪指令只支持 8 位立即数，所以需要拆分字节。

如果程序是完全顺序的，甚至可以直接把接口操作码当 `isa`：

```
; isa=<container>

ARGI.LDI #0x08
SLOT.SET
SLOT.DROP
SYS.RESET
```

反过来也是可以的，这就是元编程：

```
; isa=<epp-8-basic>
; interface=<epp-8-basic>

LDI R0, $ADD
LDI R1, #0x10
MOV R2, R0
```
