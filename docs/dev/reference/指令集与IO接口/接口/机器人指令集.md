> 设计阶段

### 0x0 系统

- `0x00` 空
- `0x01` 停止所有持续动作
- `0x02` 清空缓冲区
- `0x03` 软复位
- `0x04` 停止

### **0x1 前进**

- `0x10` 开始前进
- `0x11` 前进 1 格
- `0x12` 前进 2 格
- …
- `0x1F` 前进 15 格

### **0x2 转向/姿态**

- `0x20` 左转 90°
- `0x21` 右转 90°
- `0x22` 转 180°
- `0x23` 朝向北
- `0x24` 朝向东
- `0x25` 朝向南
- `0x26` 朝向西
- `0x27` 上看
- `0x28` 下看
- `0x29` 平视
- `0x2A` 朝向目标（寄存器）
- `0x2B` 开始后退
- `0x2C` 开始左移
- `0x2D` 开始右移
- `0x2E` 跳跃
- `0x2F` 切换潜行/疾跑/游泳模式，具体模式由寄存器决定

### **0x3 方块交互**

- `0x30` 破坏
- `0x31` 放置（使用当前选中槽）
- `0x32` 使用
- `0x33` 攻击
- `0x34` 破坏上方
- `0x35` 放置上方
- `0x36` 破坏下方
- `0x37` 放置下方
- `0x38` 破坏目标方块（寄存器）
- `0x39` 放置目标寄存器
- `0x3A` 使用目标寄存器
- `0x3B` 攻击目标寄存器
- `0x3C` 开始持续破坏
- `0x3D` 开始持续使用
- `0x3E` 精准交互，寄存器表示面
- `0x3F` *暂无*

### **0x6 即时传感器**

- `0x60` 回传自身坐标
- `0x61` 回传朝向
- `0x62` 回传速度
- `0x63` 回传血量/电量/氧气
- `0x64` 回传面前方块 ID
- `0x65` 回传脚下方块 ID
- `0x66` 回传头部方块 ID
- `0x67` 回传目标寄存器方块 ID
- `0x68` 回传姿态
- `0x69` 回传碰撞/着地/液体状态
- `0x6A` 回传光照
- `0x6B` 回传红石信号
- `0x6C` 回传时间/天气
- `0x6D` 回传维度
- `0x6E` 回传当前选中槽
- `0x6F` 回传错误码

### **0x7 扫描传感器**

部分可能涉及复杂参数，采用寄存器存参数和选择性回传

暂未定型

- `0x70` 扫描面前实体
- `0x71` 扫描周围实体
- `0x72` 扫描容器全部槽
- `0x73` 扫描背包全部槽
- `0x74` 扫描掉落物/物品展示框
- `0x75` 扫描告示牌
- `0x76` 扫描掉落物
- `0x77` 扫描玩家
- `0x78` 扫描最近容器
- `0x79` 扫描最近工作台/熔炉
- `0x7A` 扫描生物群系
- `0x7B` 扫描红石
- `0x7C` 扫描附近危险，如岩浆、火、水
- `0x7D` 扫描方块/实体属性
- `0x7E` 保留
- `0x7F` 保留

### **0x8 寄存器/参数**

很多复杂参数不要塞进单字节，而是先写寄存器。

- `0x80`\~`0x87` 写 R0\~R7，下一字节是立即数
- `0x88` 设置目标 X 低 8 位
- `0x89` 设置目标 X 高 8 位
- `0x8A` 设置目标 Y 低 8 位
- `0x8B` 设置目标 Y 高 8 位
- `0x8C` 设置目标 Z 低 8 位
- `0x8D` 设置目标 Z 高 8 位
- `0x8E` 设置槽指针
- `0x8F` 设置 Nx
