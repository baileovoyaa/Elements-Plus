红石接口是第一个IO接口类方块。

纹理：`textures/block/redstone_interface.png`（16x16）

模型使用6面正方体模型

方块实体：包含电路槽位、电池槽位、三个列表（其中一个列表包含6个磁盘槽位）

电路槽位可以放入实际电路载体

允许使用内置元件芯片和6种紫水晶元件，如果元件有配置，配置使用默认值即可

允许使用带等效元件的*_chip和创造模式元件，但不允许使用电路图

电池槽位需要放入一个紫水晶电池，没有电池不工作，只要有电池就能工作

有三个列表：未分配的引脚（可滚动）、分配的引脚（固定6项）和磁盘连接（固定6项）

引脚分配有6项（6个方向面），放入芯片时所有引脚都在“未使用的引脚”中，6个面都是空白的，可以从“未使用的引脚”拖动引脚到分配列表中，或者从分配列表中拖回未使用引脚，也可以Shift+点击快速移动。一个面只能分配一个引脚（一对一关系，不能一个引脚分配给多个面或一个面分配给多个引脚）。

使用和实验桌自定义元件配置类似的拖动效果，引脚标签前面有小方块表示输入/输出，引脚标签颜色表示位宽，悬停的行高亮，拖动到分配的引脚列表时将要放置的项也会高亮，并允许在列表内拖动（如从“北”移动到“南”）

分配引脚后，方块表面出现变化：

有引脚的面中心出现4x4平面矩形，绿色或蓝色，根据引脚输入/输出类型（输入#4488FF，输出#44FF88，和电路图中一致），上面叠一个2x2平面矩形，1位引脚用黑色到红色（根据信号强度），8位总线用恒定总线色（#FF00FF），有1位引脚的面会自动与红石相连。

8位引脚不会和红石输入输出，只能和紧邻的其他同位宽接口输入输出

磁盘列表是6个槽位+标签。电路板中的磁盘元件按（x, y）排序后依次对应1~6号槽位：放入磁盘物品即连接该磁盘，可读写并直接修改磁盘物品中的数据；放入纸带阅读器则作为只读磁盘使用，读取其打孔文件内容并忽略数据输入和 WE；空槽位相当于该磁盘元件不存在。磁盘元件不消耗物品，电路板最多包含6个磁盘元件。磁盘元件有“标签”属性（随电路图保存，默认空），有标签时槽位右侧显示该标签，否则回退显示“磁盘 N”。

磁盘物品或纸带阅读器也可以直接放入电路槽，作为自包含电路使用：磁盘暴露 WE/D/A/Y 四个引脚，外部可读写物品自身内容；纸带阅读器暴露 A/Y 两个只读引脚；两者都不占用磁盘列表的槽位，不能连接其他磁盘。

此外还有运行/暂停/单步和复位按钮，速度恒定与世界tick同步，电路模拟状态持久化存储（卸载后重新加载不会导致复位），芯片取出或更换后是复位状态

如果某个接口方块长期占用大量tick时间（或单个tick达到上限），则让该方块进入“休眠”状态，暂停其电路，播放一次“火焰熄灭”音效，并持续发出烟雾粒子（直到手动复位或继续）。

阈值可在服务端配置，包含采样刻数、平均MSPT上限和最大MSPT上限，默认采样100刻，平均上限为10ms，最大上限100ms，采样刻数为0则禁用休眠，平均MSPT上限为0则任何接口方块都会在采样刻数达到后休眠，最大上限为0则任何接口方块都会立即休眠。

注意考虑游戏暂停、单调时钟和操作系统休眠的情况，以免系统休眠后所有接口方块全部在单个tick达到上限而休眠。

界面内会显示当前机器平均MSPT，复位时显示为黑色0，正常运行为绿色，达到上限一半时显示为橙色，达到上限75%时显示为红色，单步会额外显示进行一步的求值用时，颜色使用相同着色。

## 扳手对接口方块的功能（原对管道的功能保持不变）

主手手持扳手左键接口方块（取消默认挖掘行为）选择模式：旋转引脚/分配引脚/复制配置/状态切换，按住Shift可以逆序，右键（取消打开行为，部分使用滚轮则取消快捷栏切换行为）执行操作

- 旋转引脚模式：指向面时滚动滚轮（取消默认快捷栏切换行为），引脚绕该面所在轴旋转（不影响该面和对面），右键交换该侧面与对侧面（不影响其余四个面），Shift+右键镜像整个方块（6个面均与对侧交换）
- 分配引脚模式：指向面时滚动滚轮引脚在所有未分配引脚之间循环（仅选择，不进行分配），右键确定分配，Shift+右键取消分配该面
- 复制配置模式：Shift+右键复制整个接口方块的引脚配置，右键其他接口方块粘贴，如果粘贴时引脚列表有不存在的标签，则无法粘贴
- 状态切换模式：右键运行/暂停，Shift+右键复位

增加一个按键绑定“扳手辅助操作”，默认未绑定，绑定后该按键等效于滚轮向上滚动一次（Shift+该键相当于滚轮向下滚动一次）

主手手持扳手对准接口方块时，在HUD上显示当前指向的面的朝向、引脚和扳手选择的模式，例如（方块和标签文本使用与界面相同的着色）：

```
北：■ A
模式：旋转引脚
```

```
北：■ A
模式：分配引脚
■ A
-> ■ B
■ C
■ Y
```

```
北：■ A
模式：复制配置
已复制的配置：
...
```

HUD显示在准星右侧（左上角固定），背景宽高适应内容

执行操作时，在actionbar显示提示，例如：

- “北面已分配至：■ A”
- “北面已取消分配”
- “已粘贴引脚配置”
- “无法粘贴：不匹配的引脚列表”

模式和剪贴板都是客户端临时状态，仅在操作时发到服务端，不持久化存储。
