左侧程序，右侧下方控制台，右侧上方IO/寄存器状态显示，以及可展开的内存显示

左侧上方是工具栏：运行/暂停、单步、复位、速度调节（拖到最右边是无限制）

程序可以汇编到16进制/16进制反汇编（不可逆，会丢掉标签、注释和伪指令，单独的按钮和模态框，例如点击“汇编到16进制”后弹出一个模态框显示16进制内容）

程序正在执行的行高亮。执行时不可修改程序，复位后才可以。

输入和程序运行是异步的，输入不会阻塞程序运行（除非程序用JNVI循环主动等待）。

控制台默认是文本模式，底部输入框输入后按回车将字符串字节流带换行符提交到输入缓冲区（缓冲区有数据时VI有效），输出可设置手动读和自动读，手动读可在VO有效时手动读1字节，自动读则RO始终有效。

程序读取一个字节或输出一个字节都会在控制台打印，用颜色区分输入输出。

输入缓冲区有数据时显示在输入框上方

可以切换为十六进制模式：控制台打印16进制，右侧对照字符显示（仅ASCII，不可打印字符显示为点）

输入也是十六进制，按回车提交到输入缓冲区不带换行符

支持打开文件作为输入，文本模式可以打开文本文件，二进制模式可以打开任意文件，读取一个字节文件指针+1（文件结束后VI不再有效），复位后文件指针归0。

程序区只有汇编程序一种格式，弹出的对话框只显示十六进制

“汇编到16进制”和“16进制反汇编”合并为一个按钮“16进制”，弹出包含16进制机器码的文本区域的模态框，可复制，可编辑内容后反汇编

内容未修改时反汇编按钮不可用，防止误操作

控制台增加“混合”查看模式（现在是并排模式，输入输出分开的），混合模式下，输入输出显示在同一个容器中，用文本颜色区分，例如A+B程序，输入01 02 03 04（十六进制模式），控制台打印：

```
01（蓝色） 02（蓝色） 03（绿色） 03（蓝色） 04（蓝色） 07（绿色）
```

如回显程序，输入“Hello”（文本模式），输出：

```
H（蓝色）H（绿色）e（蓝色）e（绿色）l（蓝色）l（绿色）l（蓝色）l（绿色）o（蓝色）o（绿色）
```

从而直观看出程序处理输入输出的先后顺序

文本模式下，混合模式跨输入输出的半个字符不会融合，但是输入输出连续，例如输入了“你好”（文本模式），回显可能显示为（以下?代表无法解析的字符，如字节\xe4）：

```
?（蓝色）?（绿色）?（蓝色）?（绿色）?（蓝色）?（绿色）?（蓝色）?（绿色）?（蓝色）?（绿色）?（蓝色）?（绿色）
```

A+B（文本模式）显示为：

```
?（蓝色）?（蓝色）?（绿色）?（蓝色）?（蓝色）?（绿色）?（蓝色）?（蓝色）b（绿色）
```

如果有A+B+C，显示可能为：

```
你（蓝色）A（绿色）好（蓝色）G（绿色）
```

并给予提示，混合查看模式下不连续输入输出的非ASCII字符可能不会正常显示

程序可与数据分离（可选择），这样右上角会多一个可折叠的程序ROM，与数据RAM独立
