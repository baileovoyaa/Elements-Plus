# 光刻机制造芯片逻辑

`diagramSlot` 放入带有 `EQUIVALENT_COMPONENT` 的电路图，`manufactureInputSlot` 放入四种 `*_empty_chip` 之一时，尝试制造芯片。

如果 `*_empty_chip` 的规模大于或等于电路图的规模，并且材料足够，则 `manufactureOutputSlot` 将会输出一个带有 `EQUIVALENT_COMPONENT` 组件的 `*_chip`。

因此能够输出芯片的条件是：

- 电路图具有 `EQUIVALENT_COMPONENT`
- 输出槽位放有空芯片
- 空芯片规模大于等于电路图规模（例如，规模为 `MEDIUM` 的电路图，可以制造 `medium_chip`、`large_chip` 和 `huge_chip`，而不能制造 `small_chip`）
- 物品栏内原料足够

## 关于原料统计

制作芯片所需原料来自电路图中的元件和导线。原料由若干种物品和若干种元件组成。

- 对于每个元件，读取其 `ingredientSupplier`
  - `ItemIngredientSupplier`: 读取其 `itemStacks`，添加到原料，实际需求对应种类对应数量的物品。
  - `ComponentIngredientSupplier`: 将对应元件添加到原料，实际需求带有匹配 `EQUIVALENT_COMPONENT` 的任意一种芯片（只能是四种芯片中的一种，不能是电路图或其他物品，和规模无关）。
  - `null`: 无需原料
- 对于每一格导线：
  - 如果一侧或多侧为铜，就在原料中增加一个铜线物品 `copper_wire` x1，与具体几侧无关。
  - 金线与铜线相同逻辑
  - 8位总线对应8倍原料
  - 举例：某一格导线位宽为8，北侧是铜，东侧、南侧和西侧是金，则需要8个铜线物品和8个金线物品。

如果满足制作芯片的前提条件（电路图具有 `EQUIVALENT_COMPONENT`、输出槽位放有空芯片且规模大于等于电路图规模），则统计原料并在光刻机 `manufactureWidget` 中增加对应一系列 `IngredientWidget`，物品使用 `itemStack`，元件使用元件图标，文本显示 `物品栏拥有数/总数` ，其中 `物品栏拥有数` 足够为绿色，不足为红色。（这部分源代码已经写了一部分，见 `LithographyMachineScreen:556`）

如果全部原料足够，输出槽位 `manufactureOutputSlot` 出现一个带有 `EQUIVALENT_COMPONENT` 组件的对应 `*_chip`。取出时扣除 `manufactureInputSlot` 的一个空芯片和物品栏内所需原料。如果按住Shift点击输出槽位（容器快速移动操作），可以批量制造（类似原版工作台的行为，合成直到输入槽为空或原料不足）。

考虑玩家打开界面时物品栏变化的情况（例如将物品丢出物品栏、吸取物品等），若发生物品栏变化，则更新已有原料数。
