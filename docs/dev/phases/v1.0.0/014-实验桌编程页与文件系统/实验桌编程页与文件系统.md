# 1. 总览

- 实验桌目前只有“实验”标签页，需要新增“编程”标签页。
- “编程”页是一个文件管理器 + 文件编辑器，用于管理程序、数据和外接设备内容。
- 涉及的文件系统：
  - 客户端本地文件；
  - 实验桌内存；
  - 实验桌共享空间；
  - 外接设备槽位。
- 涉及的物品/设备：
  - 已有磁盘物品（新增物品组件）
  - 新增磁盘元件；
  - 新增纸带阅读器物品（最大 1 堆叠）；
  - 新增文本文件物品（最大 1 堆叠）；
  - 新增二进制打孔文件物品（最大 1 堆叠）；
  - 已有电路图物品。
  - 已有纸 `minecraft:paper` 物品（原版 64 堆叠，但实验桌仅允许放入 1 张）。

# 2. 页面结构

## 2.1 标签页

- 保留现有“实验”标签页。
- 新增“编程”标签页。
- 两个标签页各自维护自己的选中状态和状态图标，互不共享。

## 2.2 左侧导航

- 左侧原来的章节列表替换为文件系统根列表：
  - 外接设备；
  - 实验桌内存；
  - 实验桌共享空间；
  - 客户端文件。
- 各根节点的限制：
  - “外接设备”只显示当前槽位物品对应的文件；
  - “实验桌共享空间”只显示其他玩家共享出来的文件；
  - “实验桌内存”和“客户端文件”可以新建文件和文件夹；
  - “外接设备”和“实验桌共享空间”不能新建文件或文件夹。

## 2.3 右侧区域

- 去掉右侧上方的已选实验、运行按钮和进度条。
- 顶部改为工具栏。
- 工具栏下方是搜索框，再下方是文件表格。
- 搜索框和文件表格的位置在编辑器模式下替换为多行文本编辑器或 16 进制编辑器。
- 底部增加状态栏。
- 编辑器下方增加可折叠的控制台：
  - 类似实验页的测例信息区域；
  - 目前只显示错误；
  - 与右上角状态图标配合显示失败原因。

## 2.4 状态图标

- 右上角保留状态图标按钮。
- 该按钮与实验页的状态图标按钮位置相同，但不是同一个，状态互相独立。
- 用于显示编程页的错误/状态，例如汇编失败原因、写入失败原因。
- 汇编错误同时可以显示在控制台。

# 3. 文件与容量

| 对象 | 默认上限 | 可配置 | 说明 |
| --- | --- | --- | --- |
| 磁盘物品 | 256 B | 暂不可调 | 固定容量 |
| 文本文件物品 | 32 KB | 服务端配置可调 | UTF-8 文本 |
| 打孔文件物品 | 256 B | 暂不可调 | 二进制 |
| 客户端本地文件 | 不设限 | 否 | 直接映射本地目录 |
| 实验桌共享文件 | 32 KB/文件 | 服务端配置可调 | 单文件大小上限 |
| 单玩家共享数量 | 4 个 | 服务端配置可调 | 同时共享的文件数 |
| 实验桌内存 | 32 KB 总量 | 服务端配置可调 | 含文件头，多个文件共用 |
| 客户端文本打开限制 | 32 KB | 客户端 JSON 可调 | 超过后不按文本解析 |

- 实验桌内存与方块实体持久化保存，破坏实验桌后丢失。
- 文本文件目前只支持 UTF-8 编码。
- 文件系统需要为文件保存文件头；实验桌内存的 32 KB 包含文件头。
- 客户端文件系统目录：`config/elements-plus/files`。
- 客户端本地文件不设总量限制，但客户端文本解析有单独的最大打开限制。

# 4. 文件管理器

## 4.1 通用布局

- 工具栏按钮：
  - 后退；
  - 前进；
  - 上一级；
  - 新建文件；
  - 新建文件夹；
  - 路径显示。
- 所有按钮都有悬停提示，显示按钮名称。
- 搜索框位于工具栏下方，用于搜索当前目录。
- 文件表格列：
  - 文件名；
  - 扩展名（文件夹不显示）；
  - 大小（文件夹不显示）；
  - 共享空间额外增加“拥有者”列。
- 默认按文件名排序，文件夹排在文件前面。
- 点击表头可以切换排序方式，行为类似电路图册。
- 文件夹大小在悬停提示中异步统计，表格中不显示文件夹大小。

## 4.2 客户端文件系统

- 客户端文件系统直接映射 `config/elements-plus/files`。
- 新建文件/文件夹会直接写入该目录。
- 文件表格的扩展名和大小基于实际文件。
- 支持后退、前进、上一级导航。
- 搜索只搜索当前目录，不递归。

## 4.3 选择与打开

- 单击文件：选中。
- 双击文件：进入编辑器。
- `Ctrl+点击`：多选文件。
- `Shift+点击`：区间多选。
- `Ctrl+A`：全选当前目录。
- `Ctrl+C` / `Ctrl+V` / `Ctrl+X`：复制 / 粘贴 / 剪切。
- `Delete`：删除选中项，需要确认。
- 多选和区间选择的行为可参考文件资源管理器。

## 4.4 右键菜单

以下菜单适用于客户端文件和实验桌内存；外接设备、共享空间有单独限制。

- 单文件：
  - 打开；
  - 汇编；
  - 反汇编（仅文件大小 ≤256 B 时可用）；
  - 打印；
  - 复制；
  - 剪切；
  - 粘贴（剪贴板有文件时可用，粘贴到同级目录）；
  - 共享（仅客户端文件，已共享则变为“取消共享”）；
  - 重命名；
  - 删除（需要确认对话框）。
- 多文件：
  - 复制；
  - 剪切；
  - 粘贴（剪贴板有文件时可用，粘贴到同级目录）；
  - 共享（仅客户端文件，且选择数量加上已共享数量不超过上限时可用）；
  - 删除（需要确认）。
- 单文件夹：
  - 打开；
  - 复制；
  - 剪切；
  - 粘贴（剪贴板有文件时可用，粘贴到文件夹内）；
  - 重命名；
  - 删除（需要确认）。
- 多文件夹 / 文件与文件夹混合：
  - 复制；
  - 剪切；
  - 粘贴（剪贴板有文件时可用，粘贴到同级目录）；
  - 删除（需要确认）。
- 右键空白处：
  - 新建文件；
  - 新建文件夹；
  - 粘贴（剪贴板有文件时可用，粘贴到当前目录）。
- 外接设备：
  - 只允许“打开”和“复制”。
- 共享空间：
  - 打开 / 加入协作；
  - 复制
  - 文件拥有者可以右键“取消共享”。

## 4.5 粘贴与剪切

- 粘贴到已有同名文件时，提示“覆盖”或“取消”。
- 一次粘贴多个文件且存在多个同名文件时，额外提供“全部覆盖”和“全部跳过”，作为本次粘贴剩余文件的选择。
- 剪切的文件以半透明显示。
- 剪切只有在粘贴后才真正移动文件。
- 如果剪切后又复制了其他文件，之前的剪切高亮取消，文件保持不变。
- 文件可以在表内拖动，拖动到文件夹可以移动到文件夹内，按住Ctrl键则复制到文件夹内。
- 文件剪贴板为客户端临时剪贴板（关闭实验桌/移动操作完成后清空），不是系统文件剪贴板。

## 4.6 状态栏与悬停

- 状态栏显示当前目录的文件数/文件夹数（非递归）。
- 选中文件时显示已选数量和已选文件总大小（不包含文件夹）。
- 实验桌内存额外显示一个空间占用条。
- 文件悬停提示显示：
  - 完整文件名；
  - 文件大小（或文件夹大小（异步统计））；
  - 共享文件的拥有者（若为共享空间）；
  - 正在编辑的玩家列表（若为共享文件/实验桌内存）。

# 5. 外接设备

- 当前只有一个外接设备槽位，对应槽位里放置的物品。
- 列表中的文件数量通常只有一个；纸张物品 `minecraft:paper` 不会显示在外接设备列表中。
- 可用物品及权限：

| 物品 | 权限 | 说明 |
| --- | --- | --- |
| 磁盘 | 可读写 | 固定 256 B |
| 电路图 | 只读 | 未编译的电路图可打印；见第 9 节 |
| 纸 | 只写 | 作为打印目标，不显示在列表中 |
| 文本文件物品 | 只读 | 文本文件，最大 32 KB（服务端配置） |
| 打孔文件物品 | 只读 | 二进制，最大 256 B |

- 外接设备右键只允许“打开”和“复制”。
- 选中“外接设备”时：
  - 如果槽位文件可以直接打开（磁盘/文本文件/打孔文件），则直接进入编辑器；
  - 目前只有磁盘可以直接编辑，其他只读；
  - 磁盘和打孔文件总是默认以 16 进制模式打开。
- 槽位放电路图时，先显示只有一个文件的文件管理器列表，不直接进入编辑器。
- 外接设备不能新建文件或文件夹。

# 6. 实验桌共享空间

- 显示所有玩家共享到当前实验桌的文件。
- 文件表格增加“拥有者”列。
- 有玩家正在编辑的文件显示为绿色。
- 点击可以加入协作编辑。
- 悬停显示文件拥有者和正在编辑的玩家。
- 共享限制：
  - 单文件大小默认 32 KB，可配置；
  - 单玩家同时共享文件数默认 4，可配置；
  - 超过限制的文件不能共享；
  - 编辑共享文件时达到大小上限后不能继续输入。
- 共享来源：
  - 只有客户端文件可以共享；
  - 共享后其他玩家可以在共享空间找到并加入；
  - 修改内容同步保存到文件拥有者的客户端。
- 共享生命周期：
  - 关闭实验桌后共享断开；
  - 再次点击“共享”按钮可以关闭；
  - 文件拥有者可以在共享空间右键“关闭共享”；
  - 共享断开后其他玩家的协作退出。
- 共享空间不能新建文件或文件夹。

# 7. 实验桌内存

- 容量最大 32 KB（可配置），包含文件头，由多个文件共用。
- 与方块实体持久化保存，破坏实验桌后丢失。
- 可以像客户端文件一样新建、重命名、删除文件和文件夹。
- 支持客户端文件与实验桌内存之间复制/移动，空间不足时失败。
- 有人正在编辑的文件显示为绿色，点击可以加入协作编辑。
- 悬停显示完整文件名、大小、文件夹异步大小和正在编辑的玩家。
- 状态栏额外显示空间占用条。

# 8. 文件编辑器

## 8.1 布局

- 工具栏；
- 文本编辑器（左侧行号）或 16 进制编辑器；
- 可折叠控制台；
- 底部状态栏。
- 编辑器模式下，文件管理器的搜索框和表格替换为编辑器内容；工具栏保留。

## 8.2 工具栏按钮

- 关闭；
- 汇编；
- 反汇编；
- 打印；
- 模式（文本 / 16 进制）；
- 共享（仅客户端文件）；
- 运行调试（暂不支持，按钮禁用并显示提示）。
- 所有按钮都有悬停提示，显示按钮名称。

## 8.3 文本与 16 进制模式

- 文本编辑器支持多行编辑，左侧显示行号。
- 16 进制编辑器左侧显示十六进制（类似 ROM 编辑器的网格），右侧显示 ASCII 对照。
- 打开文件时先尝试按 UTF-8 无损解析为文本：
  - 成功则进入文本模式；
  - 失败则进入 16 进制模式。
- 磁盘和打孔文件默认以 16 进制模式打开。
- 客户端配置“最大文本文件打开限制”（默认 32 KB）：
  - 超过限制的文件不尝试按文本解析，直接以 16 进制打开；
  - 该配置目前只能在客户端 JSON 中修改。
- 文本可以切换为 16 进制。
- 16 进制切换回文本时：
  - 只有能无损转换且不超过客户端文本打开限制时才直接切换；
  - 否则显示警告对话框，可以选择“强制转换”或“取消”。

## 8.4 自动保存与协作

- 编辑内容自动保存。
- 客户端文件自动写回本地文件。
- 共享文件自动同步保存到文件拥有者的客户端。
- 协作编辑效果参考 [协作编辑器](../../../../public/dev/reference/文件系统/协作编辑器/README.md)。显示其他玩家的光标和旗帜（无需动画和圆角，普通矩形旗帜即可）。
- 正在编辑的文件在文件管理器中显示为绿色。
- 状态栏显示当前编辑人数，悬停可查看具体玩家列表。
- 共享/协作断开后，其他玩家退出编辑。

## 8.5 状态栏

- 文本模式显示当前行、列。
- 十六进制模式显示字节数。
- 显示文件总大小。
- 显示当前编辑人数（若为共享文件/实验桌内存）。

## 8.6 汇编

- 对文本文件进行汇编，得到二进制程序。
- 点击后弹出对话框，选择写入槽位物品或同级目录。
- 写入槽位物品：
  - 槽位是磁盘：提示“汇编将覆盖磁盘内容，是否继续？”；
  - 槽位是纸：提示“确定将编译结果打印为打孔文件吗？”；
  - 程序超过 256 B 时失败。
- 写入同级目录：
  - 额外输入文件名；
  - 默认文件名为当前文件名去掉后缀 + `.eppbc`；
  - 同名文件提示覆盖。
- 汇编失败：
  - 在编辑器中高亮导致失败的行；
  - 右上角状态图标显示具体原因；
  - 控制台显示错误信息。

## 8.7 反汇编

- 对二进制文件进行反汇编，得到文本程序。
- 只有二进制文件大小不超过 256 B 时可以反汇编。
- 点击后弹出对话框，选择写入槽位物品或同级目录。
- 写入槽位物品：
  - 槽位物品容量装不下文本时失败；
  - 具体目标容量按槽位物品类型判断。
- 写入同级目录：
  - 额外输入文件名；
  - 默认文件名为当前文件名去掉后缀 + `.eppasm`；
  - 同名文件提示覆盖。
- 未定义的程序字节视作 `NOP`，并加注释注明原始字节。

## 8.8 打印

- 将文件内容原封不动写入外接设备（槽位物品）。
- 磁盘：
  - 超过 256 B 无法写入。
- 纸：
  - 可以选择打印为文本文件或打孔文件；
  - 打孔文件超过 256 B 无法写入；
  - 无法用文本表示，或超过文本文件上限时，无法写入文本文件。
- 电路图：
  - 见第 9 节；
  - 只允许未编译电路图。
- 文本文件物品和打孔文件物品是只读外接设备，不作为打印目标。

## 8.9 共享

- 只有客户端文件可以共享。
- 共享后文件出现在当前实验桌的“实验桌共享空间”。
- 单玩家共享文件数量默认上限 4，可配置。
- 单文件大小默认上限 32 KB，可配置。
- 超过数量或大小限制的文件不能共享。
- 编辑共享文件时达到大小上限后不能继续输入。
- 修改内容同步保存到文件拥有者的客户端。
- 关闭实验桌、再次点击共享按钮，或右键“关闭共享”，都会断开共享；其他玩家退出协作。

# 9. 电路图外接

- 槽位放电路图时，可以把电路图以 `.dat` 格式下载到本地（内容是 `CIRCUIT_DIAGRAM` 的序列化，不包含编译信息），或上传电路图。
- 上传电路图是实验性功能：
  - 服务端配置可开启；
  - 默认关闭；
  - 关闭时禁止通过实验桌上传电路图。
- 槽位放电路图时，点击左侧“外接设备”先显示只有一个文件的文件管理器列表，不直接进入编辑器。
- 文件名规则：
  - 优先使用物品的自定义名称 + `.dat`；
  - 没有自定义名称时使用元件名 + `.dat`；
  - 都没有时使用“电路图”的本地化名称 + `.dat`。
- 电路图文件只读；未编译的电路图可打印，编译后的不可打印。
- 下载：复制外接设备中的 `.dat` 文件，粘贴到客户端文件系统。
- 本地 `.dat` 文件进入编辑器时，提示对话框确认“编辑 NBT 数据可能导致损坏”。
- 上传（需要服务端配置开启）：
  - 槽位放入未编译电路图；
  - 在客户端文件系统右键一个文件，选择“打印”；
  - 尝试解析并写入电路图物品；
  - 校验失败的数据不能写入。

# 10. 磁盘

## 10.1 磁盘物品

- 磁盘物品保存 256 B 数据，固定容量。
- 等效元件是磁盘元件。
- 在实验桌外接设备中可以读写，默认以 16 进制模式打开。
- 可以手动编辑，也可以被汇编/打印写入。

## 10.2 磁盘元件

- 磁盘元件只能放置在电路板中，不能放在芯片中。
- 电路图中如果有磁盘元件，则不可编译（不能制成芯片）。
- 磁盘元件类似输入输出，是一个占位符，不消耗对应的磁盘物品。
- 一个电路板最多包含 6 个磁盘元件。
- 引脚和 256 字节 RAM 相同。
- 在光刻机设计页，这个占位符可以编辑内容：
  - 既可以手动编辑，也可以被电路编辑；
  - 只有暂停时可以手动编辑；
  - 可以切换为行视图。
- 复位后磁盘元件内容不清空，但内容不保留在电路图中，仅作为客户端临时状态；拿掉电路图会清空。
- 电路板放入接口方块后，右侧磁盘列表出现对应标签；把磁盘放入对应槽位即可连接。
- 此时电路连接真正的磁盘；如果不放磁盘，相当于该元件不存在。

# 11. 纸带阅读器

- 右键使用打开 GUI。
- GUI 中有一个槽位，可以放入打孔文件。
- 在接口方块中可以代替磁盘使用。
- 只读：忽略数据输入和 `WE`。
- 打孔文件容量最大 256 B。

# 12. 配置项

## 12.1 服务端配置

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 文本文件物品最大大小 | 32 KB | 可调 |
| 共享文件最大大小 | 32 KB | 可调 |
| 实验桌内存最大大小 | 32 KB | 可调 |
| 单玩家最大共享文件数 | 4 | 可调 |
| 允许电路图上传 | 关闭 | 是否允许通过实验桌上传电路图 |

## 12.2 客户端配置

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 最大文本文件打开限制 | 32 KB | 超过后不尝试文本解析，直接 16 进制打开；只能在客户端 JSON 修改 |

- 磁盘 256 B、打孔文件 256 B 暂不可配置。

# 13. 实现注意

- 实验桌内存文件系统文件头格式、大小和实验桌内存的分配方式。
- 共享文件拥有者离线、关闭实验桌、多人同时编辑时的相关处理。
- 电路图上传的 NBT 校验和安全限制。
- 实验与文件编辑可同时进行，实验结束不应拉回实验页。
- 操作失败时播放失败音效并显示到右上角状态图标按钮悬停提示，而不是 actionbar 或聊天栏（界面会遮挡）。
