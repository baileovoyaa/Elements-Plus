1. **方块与方向**
   - 加压机是一个方块。
   - 具有6个朝向和lit状态。
   - 前面输出，后面输入。

2. **工作条件与作用**
   - 需要消耗燃料工作。
   - 可以为密闭空间提供压强。
   - 高压空间可代替活塞，为高压结晶器提供压力值。

3. **空间判定与压强定义**
   - 不完整方块视为空气
   - 超过一定容积的空间将被视为开放空间。
   - 开放空间的压强为1.0（标准大气压）。
   - 密闭空间压强是一个浮点数。

4. **压强转移与变化规律**
   - 加压机工作时，压强会逐渐从入口端空间转移到出口端空间。
   - 实际是把空气从入口端搬运到出口端：入口端密闭空间压强减小，出口端密闭空间压强增大。
   - 压强变化遵循物理公式。
   - 空间越大，压强变化越慢。

5. **泄漏与压强上限**
   - 同时，空气会缓慢泄漏。
   - 压强偏离标准值越大，泄漏越快。
   - 因此，加压机能使空间达到的压强是有限的。

6. **与高压结晶器的联动**
   - 空间压强大于一定值时，会消耗空间内空气填充高压结晶器的压强。
   - 一个加压机所能提供压强的速度，大约可供密闭空间内3个高压结晶器工作。

7. **对生物的影响**
   - 压强偏离标准达到一定程度时，空间内的生物会受到反胃效果并受到伤害（自定义伤害类型，死于高压/低压）。
   - 处于创造模式或旁观模式的玩家不会受到影响。

8. **GUI功能**
   - 打开加压机GUI可以放燃料。
   - 燃料燃烧时间和熔炉相同。
   - 只要处于燃烧状态，就可以搬运空气。
   - 可以查看加压机流量、两侧压强和空间容积。

9. **漏斗与比较器**
   - 漏斗可以输入或抽出燃料。
   - 比较器输出格子占用情况。

## 1. 先统一模型和单位

令：

- 标准大气压 `p=1.0`（atm）；
- 偏离量 `Δ = p - 1`；
- 空间有效容积 `V`，单位用“内部空气方块数（B）”；
- 空气量 `n = p * V`，单位叫“方块·大气压（B·atm）”；
- 加压机流量 `A`：方块·大气压/秒（B·atm/s）；
- 泄漏流量 `L(p)`：方块·大气压/秒；
- 高压结晶器消耗 `c`：方块·大气压/秒。

这样所有参数都在同一量纲下，调参非常直观。

推荐公式：

```text
L(p) = C * sign(p-1) * max(0, |p-1| - d)^β
dp/dt = (±A - L(p) - Q_consume) / V
```

其中：

- `d` 是泄漏死区，避免常压附近频繁抖动，初选 `0.05~0.15`；
- `β` 控制泄漏曲线陡峭程度，初选 `2~4`，推荐 `3`；
- `C` 是泄漏系数，由你想要的最高压强反推；
- 开放空间固定 `p=1.0`，不存压强；
- 密闭空间任意轴超过 `16` 格视为开放空间。

高压结晶器建议**至少消耗平均空气流量**，否则“一个加压机供3个结晶器”没有流量意义。推荐两种方案：

1. 简单方案：工作时持续消耗 `c`；
2. 折中方案：工作时消耗维护流量 `c_maint`，每产出一次再扣一批空气 `n_item`。  
   平均消耗可折算为 `c = c_maint + n_item / t_item`。

## 2. 用目标反推参数

先定四个体验目标：

- 工作压强 `p_work`，例如 `2.0` 或 `2.5`；
- 最高压强 `p_max`，建议 `p_work + 0.5~1.0`；
- 一个加压机把 `V_max` 从 `1.0` 加到 `p_work` 的时间 `t_fill`，建议 `30~120s`；
- 在工作压强下，泄漏占加压机流量的比例 `r`，建议 `10%~25%`。

反推公式：

```text
p_max = 1 + d + (A / C)^(1/β)
C = A / (p_max - 1 - d)^β

r = L(p_work) / A
  = ((p_work - 1 - d) / (p_max - 1 - d))^β
```

如果先定 `r`，可以反推最高压强：

```text
p_max = 1 + d + (p_work - 1 - d) / r^(1/β)
```

加压机流量初算：

```text
A ≈ V_max * (p_work - 1) / t_fill
```

实际实现含泄漏，建议先把 `A` 取计算值的 `1.1~1.3` 倍，再仿真微调。

一个加压机供3个结晶器：

```text
c = (A - L(p_work)) / 3
```

这样“供3个”是指在目标压强下，扣除泄漏后还能维持3个结晶器同时工作。

## 3. 一套可直接试的初始参数

推荐先做“较安全、可建造”的方案：

| 参数 | 初值 | 说明 |
|---|---:|---|
| `V_max` | `4096` | 16×16×16 内部空气方块 |
| `p_work` | `2.0` | 高压结晶器工作压强 |
| `p_max` | `3.0` | 泄漏封顶压强 |
| `d` | `0.1` | 泄漏死区 |
| `β` | `3` | 泄漏幂律指数 |
| `t_fill` | `60s` | 从1.0到2.0约1分钟 |
| `A` | `≈2.08` | 由 `125*1/60` 得 |
| `C` | `≈0.304` | 由 `A/(3.0-1-0.1)^3` 得 |
| `L(2.0)` | `≈0.222` | 占 `A` 约10.6% |
| `c` | `≈0.62` | 每个结晶器平均消耗 |
| 3个结晶器总消耗 | `≈1.86` | 加泄漏约2.08 |
| 每件耗气 `n_item` | `10` | 则单件约 `10/0.62≈16s` |

伤害参数可以这样起步：

| 参数 | 初值 |
|---|---:|
| 反胃阈值 `Δ_nausea` | `0.7`，即 `p>1.7` 或 `p<0.3` |
| 高压伤害阈值 `Δ_dmg_high` | `1.25`，即 `p>2.25` |
| 低压伤害阈值 `Δ_dmg_low` | `0.9`，即 `p<0.1`，可附加窒息 |
| 高压伤害系数 `k_high` | `0.75~1.0 心/秒/Δ` |
| 低压伤害系数 `k_low` | `1.0~2.0 心/秒/Δ` |

伤害公式：

```text
高压DPS = k_high * max(0, (p-1) - Δ_dmg_high)
低压DPS = k_low  * max(0, (1-p) - Δ_dmg_low)
```

这套参数下，`p=2.0` 工作时只会反胃、不受伤；`p=2.25` 开始缓慢受伤；`p=3.0` 时高压伤害约 `0.75 心/秒`。如果希望更危险，可把 `p_work` 提到 `2.5`、`p_max` 提到 `3.5`，并把伤害阈值设到 `1.2` 左右，让工作区本身就有轻微伤害。

## 4. 参数选择顺序

建议严格按这个顺序调：

1. **定 `V_max`**：按典型房间大小和一个加压机服务范围定。超过就视为开放空间，并给可视化提示。
2. **定 `p_work` 和 `t_fill`**：先保证空空间能在可接受时间内达到工作压强。由这两个反推 `A`。
3. **定 `p_max`、`d`、`β`、`r`**：先决定“超压封顶在哪”，再反推 `C`。推荐 `β=3`，因为它能让工作压强下泄漏不高、超压时泄漏迅速上升。
4. **定结晶器消耗 `c`**：用 `c=(A-L(p_work))/3` 保证一个加压机带3个。若想留余量，取 `c` 小 `10%~20%`。
5. **定每件耗气和产出时间**：`n_item = c * t_item`。例如想让单件16秒，就取 `n_item≈10`。
6. **最后调伤害和反胃**：让反胃阈值略低于工作压强作为警告，伤害阈值略高于工作压强作为缓冲；最高压强处DPS控制在 `0.5~1.0 心/秒`，不要秒杀。

---

## 5. 调参时看这几个指标

每改一版参数，记录：

- 空空间从 `1.0` 到 `p_work` 的实际时间；
- 3个结晶器同时工作时，压强是否稳定在 `p_work ± 0.1`；
- 满载时压强下降多少，建议小于10%；
- 从 `p_work` 泄漏到 `1.5` 需要多久；
- 超压到 `p_max` 需要多久；
- 玩家在 `p_work`、`p_max` 处的反胃/伤害体感；

---

## 6. 实现上的关键注意

- 压强用服务端 `double` 存，客户端只同步显示；每 `1~5 tick` 更新一次即可。
- 密闭空间检测不要每 tick 全量 flood fill；用方块变化触发或每 `20~100 tick` 缓存刷新。
- 多个加压机连接同一密闭空间时，压强不能各算各的，否则会冲突。要做共享空间网络。
- 开放空间固定 `p=1.0`。
