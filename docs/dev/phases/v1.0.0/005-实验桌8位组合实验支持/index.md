# 随机测例

目前测例都是恒定输入的，但现在我们要加入一种新的类型的测例。

> [电路实验#随机测例](../../../reference/%E5%AE%9E%E9%AA%8C/%E7%94%B5%E8%B7%AF%E5%AE%9E%E9%AA%8C.md#随机测例)

8位加法器的测例一共有256个，可以参考[8位加法器测例生成.py](../../../reference/实验/电路/8位加法器测例生成.py)的生成逻辑。对于每个测例，都会对每个输入非0位随机一个1~15的值，以确保电路正确处理了信号强度。
