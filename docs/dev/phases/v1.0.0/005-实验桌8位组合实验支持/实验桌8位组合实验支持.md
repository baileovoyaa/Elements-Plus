目前实验章节已经写到了多位加法器部分，需要处理8位的输入和输出，以及随机测例。

# 8位输入输出

8位输入和8位输出元件已经添加，但目前尚无功能。

8位输入有1个标签属性和8个滑块属性（分别对应每一位的0~15信号强度），双击可以打开一个类似元件列表组重命名的对话框，输入框自动填入当前数字值，输入0~255的数字点确定后8个滑块设为对应二进制（1对应15，0对应0）

8位输出只有1个标签属性。

8位输入输出元件上显示的数字是0~255的数字，表示当前输入/输出二进制对应的十进制数。非0视为1，0视为0。数字文本颜色是8位总线色（0xFF00FF）。

同样，8位输入输出也要做好预检、测例适配和写回，预检时检查位宽（例如实验要求输入A是8位，但实际上持有标签A的是一个一位输入元件，则预检不通过）。

# 随机测例

目前测例都是恒定输入的，但现在我们要加入一种新的类型的测例。 这种测例每次运行的值不固定。

注意：随机数在测例运行时动态生成，每次运行可能都不同，不要在静态初始化时生成随机数。

8位加法器的测例一共有256个，可以参考[8位加法器测例生成.py](../../../reference/实验/电路/8位加法器测例生成.py)的生成逻辑。对于每个测例，都会对每个输入非0位随机一个1~15的值，以确保电路正确处理了信号强度。
