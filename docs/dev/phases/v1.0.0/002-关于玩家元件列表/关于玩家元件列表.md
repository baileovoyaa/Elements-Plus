# 关于玩家元件列表

## 概述

截止到目前版本，界面中可用的元件列表仍是预先定义且全局通用的（`BuiltinCircuitComponents.EXAMPLE_TOOLBOX`）。

不过按照最终设计，这个元件列表是要逐玩家存储，且支持自定义的。玩家可以添加和删除元件、自定义分组和顺序。除了某些内置的元件和分组（总线和输入输出），玩家都需要通过其他方式获得这些等效元件，然后才能使用，并可以将它们添加到元件列表，便于以后设计时快速取用。

“总线”和“输入输出”是内置分组，新玩家默认拥有这两个分组。可以移动这些分组的顺序，但不能删除，也不能往这些分组里添加元件或删除元件，或调整分组内元件的顺序。

玩家可以创建自定义的分组，可以调整分组的顺序、分组内元件的顺序、重命名分组、在自定义分组之间移动元件，也可以删除自定义分组。

为了实现这些功能，我们需要实现多个功能模块，包含拖动、右键菜单和对话框，以及存储。

## 具体交互实现

目前玩家折叠分组、从列表中拿取元件都是按下时执行，为了实现拖动调整顺序，这些都要改为松开时执行。

为了使底部有空白处可以点击，列表的底部会留出50px空间，并在此处显示文本“右击添加新分组”（具体功能下面所述）。

添加元件（注意原版物品堆叠是点击拿起的，不是拖动，和后面的移动分组或元件不一样）：从物品栏拿起的真实元件（包含 `equivalent_component` 物品组件的物品堆叠，从列表拿起的虚拟元件不算）在自定义分组内缝隙处点击，就可以插入到该分组中。如果可插入，就会在缝隙处显示一条粗线。如果悬停在列表底部空白处，此处会出现一个矩形，点击可以添加一个新“未命名分组”并将元件放进去。

移动分组：拖动分组的折叠按钮可以调整分组顺序，此时所有分组会临时都变成折叠状态（便于跨多个分组拖动），鼠标拖到的缝隙处会显示一条粗线表示将要插入到这里，松开鼠标完成移动，所有分组恢复原先的折叠/展开状态。

移动元件：拖动自定义分组中的元件可以调整元件顺序，可以拖到其他自定义分组中，同样，如果可以移动到此处，缝隙显示一条粗线。松开鼠标完成移动。

移动分组或元件时，如果鼠标拖出了列表上下界，则列表会往超出的方向缓慢滚动。拖动时会有虚影跟随鼠标。

删除元件、重命名分组、添加分组：通过右键菜单，下面所述。

### 右键菜单

需要实现一个右键菜单（右键时显示的一个按钮列表），以进行删除元件、重命名分组、添加分组等操作。右键菜单可以是一个最后绘制的按钮列表，覆盖在其他内容上，并在点击其他位置或执行完操作时消失。

自定义元件的右键菜单包含一个“删除”按钮，点击可以从列表中移除此元件。

内置分组的右键菜单只有“插入新分组”按钮，点击后在前面插入一个“未命名分组”。

自定义分组的右键菜单有“插入新分组”“重命名分组”“删除分组按钮”：

- “插入新分组”按钮可以在该分组前面插入一个“未命名分组”
- “重命名分组”将会弹出一个下文所述的对话框，玩家点击确定后应用名称。
- “删除分组”会删除整个分组，如果分组非空，则弹出对话框要求确认（与此不同，删除元件不需要确认，因为删除单个元件很容易添加回来）。

列表底部的空白部分的右键菜单有“添加新分组”，点击后在列表最后添加一个“未命名分组”。

内置元件没有右键菜单。

### 对话框

需要实现一个对话框，以实现分组的重命名和删除确认。对话框可能包含输入框，以及两个按钮“确认”和“取消”。

显示对话框时需要在其他内容上方绘制一个覆盖全屏的半透明的黑色遮罩层，并禁用其他内容的交互，然后可以使用 `GuiUtil.drawMainPanel` 绘制窗体，然后按需绘制标题和操作按钮。ESC键此时为取消对话框操作，而不是直接关闭屏幕。

“重命名分组”对话框包含一个输入框（默认填入分组的当前名称），“取消”和“确定”按钮

“删除分组”对话框只显示一条文本 `确定删除分组"XXX"？该分组及其所有元件都会被删除` ，以及“取消”和“确定”按钮。

### 细节说明

分组与分组之间的缝隙处相当于追加到前一个分组的末尾。例如：

```
[分组A]  // 没有元件或已折叠
------  <-- 分组A的末尾
[分组B]
  元件A
  元件B
------  <-- 分组B的末尾
[分组C]
  元件C
  元件D
------  <-- 分组C的末尾
(空白处) <-- 创建新分组
```

## 存储

玩家元件列表是持久存储在服务端的，各存档独立。可以通过Fabric Data Attachment API等方式附加到玩家数据。客户端与服务端建立连接时可能会拉取并缓存，但最终还是存在服务端玩家数据中的。客户端进行修改后也要与服务端同步。
