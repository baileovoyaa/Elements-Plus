[自定义元件](../../../../user/experiment-chapters/custom-component.md)是一个特殊的章节，实验会编译电路图，但是关联的不是内置元件而是自定义元件。

自定义元件可能会被复制很多份，因此需要修改存储方式。

# 分离存储

已编译电路图的电路将不再直接存物品里，而是永久写入存档的data子目录中（data/elements-plus/circuits/\<uuid\>.dat），物品里只留引用，这样方便查找，也可以减少数据冗余。这个修改同时应用于内置元件和自定义元件。

这样复制已编译的电路图，在保留编译状态的情况下，复制的还是同一份引用，由于已编译的电路图无法修改，这没有问题。如果不保留编译状态，则会将文件中的内容写入到新的可编辑电路图物品中。

这样一来，所有的已编译电路图都会拥有一个uuid，表示其引用的电路。这个uuid显示在元件名下方。

如：

```
电路图
与门
<uuid>
规模：小
```

```
电路图
*自动开关门控制器*
作者：xxx
<uuid>
规模：小
```

存档的自定义元件不仅包含电路信息，还有元件的一系列元数据，如名称、图标、颜色、宽高、引脚分布等。另外都存有编译电路的玩家uuid（实验的发起者）。

# 新增命令

```
/elements-plus circuit give <元件名/uuid>  # 获取电路图
/elements-plus circuit list all  # 列出所有已编译电路
/elements-plus circuit list player <玩家>  # 列出某个玩家创建的电路
/elements-plus circuit list name <元件字符串名>  # 列出所有同名元件（内置元件用id字符串）
/elements-plus circuit list id <uuid>  # 显示对应uuid的电路图信息，不获取物品
/elements-plus circuit <recall|clean> <all|player <玩家>|name <元件字符串名>|id <uuid>>  # 列出/清理丢失（未使用）的电路（暂不用实现）
```

使用命令 `/elements-plus circuit give <元件名/uuid>` 可以获得对应元件名/uuid的电路图。uuid与元件名同名时，uuid优先。元件名有多个重复时报错，并列出所有同名元件的创建者和uuid，增加点击事件，点击可以输入 `/elements-plus circuit give <uuid>` 到聊天栏（类似原版locate命令反馈的点击事件）。

使用命令 `/elements-plus circuit list ...` 可以列出一系列元件，包括元件名、创建者和uuid，点击事件同上。

# 自定义元件配置与编译

玩家需要放入电路图、选择自定义元件的实验，然后填写表单，点击开始按钮直接编译。

首先是名称。内部元件的字符串名称是元件id（如and\_gate），自定义元件名称不能和内部元件id重复（可以是本地化名称“与门”，但不能是“and\_gate”），可以和其他自定义元件重复（uuid区分）

描述是可选的，默认为空

图标可选字符或物品

- 字符：字符串作为替代图标
- 物品：使用物品作为替代图标，拿起物品点击设置，不消耗物品

如果都没有，使用对应规模的chip（如 `elements-plus:medium_chip`）作为图标。

颜色是元件矩形块的颜色，默认是灰色。

元件宽度和高度范围都是1\~16。

- 宽高默认调整为可装下元件所有可用引脚的最小正方形，根据输入/输出元件相对位置进行初始分布。放入电路图/选择此实验时自动进行，提供“一键分配引脚”按钮重新进行此过程（覆盖已有的宽高设置和引脚分布）

预览：

- 可以看到整个元件矩形及引脚分布，和电路图内一样的渲染效果，并且引脚外侧显示引脚标签文本（过长截断，悬停可查看完整标签），文本颜色使用位宽，单侧对齐（左侧右对齐，右侧左对齐，上下侧文本旋转90度），整体等比缩放到宽度适合。
- 拖动引脚（或标签文本）可以移动在边缘上的位置，以下操作可以移除单个引脚分配（移到未使用的引脚列表）：
    - 拖动距离过远
    - 拖到未使用的引脚列表中
    - shift+点击
    - 右键点击
- 拖动引脚到其他引脚上默认会取消操作，松开鼠标时如果按住shift则会覆盖掉此引脚位置。
- 缩小宽度和高度会移除缩短侧索引较高的引脚。

未使用的引脚列表显示所有未分配、不为空、不为VCC的引脚。

- shift+点击列表中的一个可用项，该引脚会分配并插入到第一个空位（满了则无操作）。
- 标签重复的也会显示在未使用的引脚列表，但是不可用（不可拖动，不能被分配），悬停会提示输入/输出标签重复。

在求值时，自定义元件子电路的输入输出会被引脚输入输出取代，为空/未分配的输入输出会被视作0，带VCC标签的输入视为15（不暴露在引脚上）。

如果存在组合环，不能编译自定义元件。

# 制造逻辑

制造内置元件芯片仍保留原有制造逻辑，因为同一种内置元件的逻辑是固定的。

但是，制造自定义元件时就需要带uuid引用了。

同样，制造高阶芯片统计所需材料时，自定义元件要求对应uuid的芯片（材料列表悬停时不仅显示元件名，也会显示uuid），而不只是同名。内置元件仍是原有逻辑（不强制要求某种实现）。

# 元件列表

元件列表自定义元件悬停提示不仅显示名称和描述，还显示uuid、作者和规模

自定义元件不能放在相同或更小规模的电路图中，以防过度嵌套，但无限可以放入无限。内置元件无此限制。
