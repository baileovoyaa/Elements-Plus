# 同步文本框

一个无需第三方库的多人实时协作文本框。Python 标准库后端 + 原生 HTML/CSS/JS 前端。

## 运行

```bash
python app.py
```

浏览器打开 <http://127.0.0.1:8000>，输入用户名即可编辑。多开几个标签页、窗口或设备访问同一地址即可看到同步效果。

- 修改端口：`PORT=9000 python app.py`（PowerShell 用 `$env:PORT=9000; python app.py`）
- 同一局域网的设备可用 `http://本机IP:8000` 访问（Windows 防火墙需放行）。

## 功能

- 所有人共享同一段文本，多人同时编辑。
- 其他用户的光标为彩色竖线，上方旗帜显示用户名。
- 用户加入、编辑或移动光标后，旗帜显示 2 秒；鼠标悬停光标可随时查看。
- 光标层不拦截鼠标，点击其他用户光标所在位置也能直接定位。
- 其他用户选择文本时显示同色半透明底色。
- 光标锚定在字符本身（CRDT）而非固定下标，其他人的插入、删除会让光标跟随文本移动。
- 输入框失焦不会移除光标，重新聚焦时更新位置。
- 支持中文输入法组合输入：组合期间冻结远程光标位置，结束后一次性合并，避免光标漂移。

## 实现简述

- 后端：`ThreadingHTTPServer`，SSE 推送事件，POST 提交编辑与光标；无数据库，文档保存在内存中。
- 前端：每个字符有唯一 ID，按“父字符”组成序列 CRDT；光标保存字符 ID，因此并发编辑时仍能跟随文本。文本框上方用隐藏镜像层测量位置，绘制远程选区和旗帜。
