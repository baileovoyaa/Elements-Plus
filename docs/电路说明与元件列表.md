## 逻辑层

电路有16级信号强度（0~15），对于同一个导线网络有多个驱动源的情况，在所有驱动源中取最大值，因此任一驱动源为15则该导线网络的信号强度就是15，前提是不存在循环依赖

信号强度在导线中传播不会衰减。

铜线和金线各不相连，也就是铜线的信号无法不通过其他组件转移到金线上，反之亦然。这可以方便区分和交叉布线。理论上组件引脚只能连接一种类型的导线（因为该引脚前的格子要么是导线要么是元件，是导线的话指向该元件方向的一侧要么是COPPER要么是GOLD，由枚举值决定的）

组件输出同样可直接指向相邻组件输入，此时元件可不经过导线传递信号

## 交互层

导线内层默认黑色，有信号时变红，0~15对应不同亮度的红色（如果同一格导线里既有铜线也有金线，那么这格导线相当于持有两路信号，对应侧变对应色）

对于循环依赖的导线，导线保持黑色，并在该导线网络所有格上叠加显示elements-plus:textures/gui/cycle.png，电路图底部显示警告信息，存在循环依赖时无法运行。

现阶段为纯客户端逻辑，只在对应界面进行模拟，电路模拟状态并不会持久化到物品组件或发送到服务端。

## 元件列表

> 此处方位词对应默认朝向，而不是旋转后的

### 晶体管

具有两个输入和一个输出，`输出 = min(floor(2 * 西输入 * (1 - 南输入 / 15)), 15)`

### 二极管

具有一个输入和一个输出，`输出 = 输入`

### 电阻

> 原先设计是倍率，但是考虑到 Minecraft 信号线性衰减的特性，同时为了规避浮点误差带来的麻烦，现改用线性衰减。源码已作相应更改。

参数：衰减，整形，范围0~15，默认1

具有一个输入和一个输出，`输出 = max(输入 - 衰减, 0)`

### 电容

**时序元件**

具有一个输入和一个输出

参数：

- 充电速度（整形0~15，默认15）：当前输入大于当前输出时，下一刻输出应该增加的最大量（不会超过当前输入）
- 放电速度（整形0~15，默认15）：当前输入小于当前输出时，下一刻输出应该减小的最大量（不会低于当前输入）

最初输出为0，设下一刻输出为Q1，当前刻输入为D，当前刻输出为Q，则：

```
if (D > Q) {
    Q1 = min(Q + 充电速度, D)
} else if (D < Q) {
    Q1 = max(Q - 放电速度, D)
} else {
    Q1 = Q
} 
```

因此，当充放电速度都是15时，其作用相当于DFF，将输入延迟一刻输出

### 谐振器

具有一个输入和一个输出。

参数：

- 高电平保持（整形1~20，默认1）：保持输入信号强度的持续刻数
- 低电平保持（整形1~20，默认1）：保持0信号强度的持续刻数
- 初相（整形0~40，默认0）：从复位后开始模拟相当于从第几刻开始，影响最初处于高电平还是低电平，以及最初状态的持续时间

某一刻的输出取决于其所在的相位，只能是输入或0，一个周期=高电平保持+低电平保持

### 电池

具有一个输出

持续输出15信号（不可调节）

### 输入

具有一个输出

参数：虚拟输入信号（0~15，默认0）

作为外部输入源，在电路图中模拟时可以调节任意信号（0~15），双击组件可以在0和15之间快速切换（不为0则变成0，为0则变成15），同时在格子上显示当前输出强度的数字，覆盖在图标上方

### 输出

具有一个输入

输出到外部电路，在电路图中模拟时具有特殊渲染逻辑：在格子上显示当前输入强度的数字，覆盖在图标上方

### 与门

具有两个输入和一个输出

需要注意的是，这个与门类似编程语言中的“短路与”，输入A（西0）和B（西1），如果A不为0则输出B，否则输出0
