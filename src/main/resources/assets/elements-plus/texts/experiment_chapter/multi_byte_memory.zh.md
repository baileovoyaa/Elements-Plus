前面的寄存器一次只能保存一个值。如果有很多数据要保存，并且希望按编号随时取出其中任意一个，就需要一种容量更大的元件——<color=blue>存储器</color>。

存储器内部被划分为许多<color=blue>存储单元</color>，每个单元保存一个字节（8 位，正好是一条 8 位总线的宽度）。为了区分这些单元，我们给每个单元编一个<color=blue>地址</color>。访问数据时，只要给出地址，就能找到对应的存储单元。这种可以按地址直接访问任意单元的存储器，叫做<color=gold>随机存取存储器</color>（RAM）。

**这里的“随机存取”是指可以直接访问任意地址，而不必从前往后依次查找，和“随机数”没有关系。**

以下存储器只存数字信号，输入只看0/非0，输出都是0或15，不会保存信号强度。

---

先来看容量最小的<color=gold>4字节随机存取存储器</color>。

- <color=gold>4字节随机存取存储器</color>：输入 A（8位，数据）、D（8位，地址，仅低 2 位有效）、WE（1位，写选通），输出 Y（8位，数据）。共有 4 个存储单元，地址为 0~3，对应 D 的低 2 位；D 的高 6 位会被忽略。

它的引脚含义如下：

- A（8位）：数据输入，要写入存储器的数据；
- D（8位）：地址输入，选择要访问的存储单元；
- WE（1位）：写选通，决定是否写入；
- Y（8位）：数据输出，输出 D 地址当前保存的数据。

它的读写规则是：

- **读取是组合逻辑**：在组合逻辑求值时，Y 会直接输出 D 地址对应的数据。也就是说，只要改变 D，Y 就会跟着变化，不需要等待时钟步进。WE 不参与地址选择，Y 始终输出 D 地址的数据。
- **写入是时序逻辑**：当时钟步进时，若 WE 非 0，就把 A 的数据写入 D 地址；若 WE 为 0，存储器内容保持不变。
- 读和写使用同一个地址 D。在 WE 非 0 的时钟步进中，写入的是 D 地址，Y 输出的也是这个地址的数据；由于写入在时钟步进时生效，步进完成后 Y 就会反映新写入的值。
- WE 不是边沿触发。只要每个时钟步进时 WE 都非 0，每个 tick 都会写入一次；不想继续写入时，要把 WE 置 0。

使用时，把要访问的地址接到 D。只读取数据时，让 WE 保持 0，直接从 Y 取结果；要写入时，把数据接到 A，让 WE 非 0，时钟步进后，再把 WE 置 0。

```epp-experiments
elements-plus:ram_4
```

把容量扩大，就得到 16 字节、64 字节和 256 字节的版本。它们的引脚和读写规则完全相同，只是地址位数不同：

- <color=gold>16字节随机存取存储器</color>：D 的低 4 位有效，共 16 个单元，地址 0~15；
- <color=gold>64字节随机存取存储器</color>：D 的低 6 位有效，共 64 个单元，地址 0~63；
- <color=gold>256字节随机存取存储器</color>：D 的 8 位全部有效，共 256 个单元，地址 0~255。

所有容量的存储器都使用 8 位地址，这样在电路中可以共用同一套地址总线；容量较小时，超出的高位直接忽略即可。

需要特别注意：随机存取存储器是<color=blue>易失性存储器</color>，它的内容只在电路运行时有效。电路复位或断电后，RAM 中的数据会全部丢失，也不会随电路图或芯片一起保存。因此 RAM 适合存放程序运行过程中的临时数据；需要长期保存的内容，应当使用只读存储器或磁盘。

```epp-experiments
elements-plus:ram_16
elements-plus:ram_64
elements-plus:ram_256
```

<color=gold>256字节只读存储器</color>的引脚更少：

- D（8位）：地址输入，选择要读取的存储单元；
- Y（8位）：数据输出，输出 D 地址保存的数据。

和 RAM 不同，ROM 没有 WE，电路运行时不能写入，只能读取。它的内容不是运行时数据，而是元件的配置：在设计时写入电路图，并随电路图或芯片永久保留，复位或断电都不会丢失。

不过，ROM 是真正的“只读”：内容不可擦写，一经编译就不可修改。编译后的电路图或芯片中的 ROM 内容就固定下来了；如果发现数据有误，只能修改设计后重新编译。

在编译之前，你可以在设计界面中双击 ROM 元件打开它的编辑对话框，直接编辑这 256 个字节的内容。由于数据较多，逐字节手动输入很麻烦，编辑界面支持从磁盘复制数据，可以先用磁盘准备好内容，再一次性导入。

- <color=gold>256字节只读存储器</color>：输入 D（8位，地址），输出 Y（8位，数据）。共有 256 个存储单元，地址 0~255。

这个实验是可选的，暂时用不到 ROM 也可以先跳过。

---

由于手动搭建 256 字节的 ROM 很麻烦，因此只需搭建一个 16 字节的 ROM 即可通过实验。使其低 4 位有效，存储的内容如下：

```epp-text
elements-plus:rom_values
```

制造 ROM 芯片本身时，所需的材料会对应乘以 16 倍。

```epp-experiments
elements-plus:rom_256
```

最后介绍<color=gold>磁盘</color>。

磁盘是一种可以合成的物品。它和前面两种存储器不同：数据保存在磁盘物品本身，而不是保存在电路图的元件里。

在电路图中放置的磁盘元件只是一个<color=blue>占位符</color>，用来表示“这里会连接一块磁盘”。真正保存数据的是在具体 IO 接口中连接的那块磁盘物品。如果没有连接真实的磁盘物品，这个占位符本身是没有数据的。

只要连接了真实的磁盘物品，磁盘中的数据在电路复位、断电后也不会丢失，可以长期保存程序和数据。与 RAM 相比，磁盘是<color=blue>非易失性</color>的；与 ROM 相比，磁盘可以更换，内容也可以修改，而 ROM 的内容在编译后就固定了。

你可以在实验桌内编辑磁盘内容；前面提到的 ROM 编辑界面，也可以直接从磁盘复制数据。

在后面的计算机架构章节中，我们会把程序和数据放进存储器，让计算机按地址访问它们。届时你会看到，正是“地址 + 数据”这两个概念，把运算、存储和控制连接在了一起。
