现在架构已经能取指、读寄存器、读写内存，但还不能做计算。本章把<font color=gold>多功能运算器（基础版）</font>接进来，加入 8 条 ALU 指令。

取指接口与上一章相同：`PC` 输出到虚拟程序 ROM，`INS` 输入指令；架构仍然每 tick 执行一条指令。

## 连接 ALU

基础版 ALU 的引脚：

- `A`（8位）、`B`（8位）：两个操作数；
- `OP`（8位）：操作码，只有低 3 位有效；
- `CI`（1位）：进位输入；
- `Y`（8位）：运算结果；
- `CO`（1位）：进位输出。

连接方式：

- `A` 接 `R0`；
- `B` 接 `R2`，也就是 `mem[R1]`；
- `OP` 接 `INS` 的低 3 位（`INS[2:0]`）；
- `CI` 接 0；
- `Y` 接 `R0` 的写回数据；
- `CO` 不接，本章不使用进位。

ALU 是组合逻辑：结果在当前 tick 内算出，`R0` 在时钟步进时更新。`R0` 的写使能需要覆盖所有会写 `R0` 的指令：`MOV`、`LDL`/`LDH` 和本章的 ALU 指令。写回数据也要用 mux 在“MOV 源”“立即数”和“ALU 的 Y”之间选择。

## 本章指令

| 汇编 | 机器码 | 十六进制 | 效果 |
| --- | --- | --- | --- |
| `ADD` | `0010 0000` | `0x20` | `R0 <- R0 + mem[R1]` |
| `SUB` | `0010 0001` | `0x21` | `R0 <- R0 - mem[R1]` |
| `AND` | `0010 0010` | `0x22` | `R0 <- R0 & mem[R1]` |
| `OR` | `0010 0011` | `0x23` | `R0 <- R0 \| mem[R1]` |
| `NOT` | `0010 0100` | `0x24` | `R0 <- ~R0` |
| `XOR` | `0010 0101` | `0x25` | `R0 <- R0 ^ mem[R1]` |
| `SHL` | `0010 0110` | `0x26` | `R0 <- R0 << (mem[R1] & 7)` |
| `SHR` | `0010 0111` | `0x27` | `R0 <- R0 >> (mem[R1] & 7)` |

说明：

- 两个操作数固定是 `R0` 和 `mem[R1]`，结果固定写回 `R0`；`mem[R1]` 不会被修改。
- `SUB` 是 `R0 - mem[R1]`，不是反过来。
- `NOT` 是单目运算，忽略 `mem[R1]` 的值；结果不依赖它，也不会修改内存。
- `SHL`/`SHR` 的移位量取 `mem[R1]` 的低 3 位，范围 0~7；移出的位舍弃，空缺位补 0。它们是**逻辑移位**。
- 加减法按 8 位回绕，不保留进位/借位，也没有 flags；条件判断要等跳转章节直接比较数值。
- `0010 1XXX`（`0x28`~`0x2F`）是 ALU 第二页，留给高级功能；基础版按 NOP 处理。

## 示例

假设 `R0=0x0A`，`R1=0x20`，`mem[0x20]=0x03`：

```text
ADD             ; 0x20，R0 <- 0x0A + 0x03 = 0x0D
MOV R3, R0      ; 0x33，输出 0x0D
NOP
```

再做一次减法：

```text
; R0=0x0A，mem[0x20]=0x03
SUB             ; 0x21，R0 <- 0x0A - 0x03 = 0x07
MOV R3, R0      ; 0x33
NOP
```

`R1` 的地址仍然要用 `LDL`/`LDH` 或 `MOV` 提前设置好；ALU 只负责读 `mem[R1]`，不会自动改变地址。

## 注意

- ALU 的 `OP` 只使用低 3 位，正好对应 8 条指令；`CI` 固定为 0，`CO` 忽略。
- ALU 的结果是组合逻辑，必须在同一 tick 内稳定；ALU 的结果只应在 ALU 指令时选为 `R0` 的写回数据，`R0` 的整体写使能仍要覆盖 `MOV`、`LDL`/`LDH` 和 ALU 指令。
- 本章只使用基础版 ALU；高级版的乘法等功能不在计算机架构的必做范围内。
- 本章仍然没有跳转，程序按 `PC` 顺序执行。
